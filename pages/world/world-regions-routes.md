# 主島エリア分け・街道

ワールドマップ確定座標と開発用イメージを基準にした、主島の地形エリアと街道ネットワーク。

目的は、見た目上の地域差だけでなく、**実際にプレイヤーが歩いて探索することを前提にした移動構造**を作ること。

## 基本方針

- 主島は大きく **7エリア** に分ける。
- エリア境界は厳密な直線ではなく、山裾・川・植生・地表色などで自然につながる。
- 町と町を結ぶ主要街道は存在するが、すべてを最短距離の直線で結ばない。
- 一本道だけにせず、支道・旧道・獣道・川沿いの迂回路を置ける余白を残す。
- 高山・崖・深い湿地・大河などは移動を制限するが、主島内で「カード枚数が足りないから通れない」ような人工的なゲートは原則使わない。
- 基本的には序盤からどこへでも向かえる。ただし環境や危険度によって「今行くと大変」は作る。

# 7つの主要エリア

## 1. 北部山岳地帯

**おおよその範囲：** `x=6,200〜10,000 / y=850〜3,100`

中心：**カルドラント** `(8,000,2,000)`

- 主島最高峰を含む雪山・岩山・高地草原。
- 山脈は東西方向へ広がり、南側へ複数の尾根が伸びる。
- 完全な壁にはせず、主要な山道と2〜3本の細い峠道を持つ。
- 北へ行くほど積雪・寒冷の影響が強い。
- カルドラントは鉱山都市で、周辺の鉱石・金属資源と鍛冶文化を基盤に発展している。
- スカルドからこの山岳地帯へつながる、外からは分かりにくいルートが存在する。構造・入口・発見条件は未確定。

## 2. 西部大森林

**おおよその範囲：** `x=3,100〜6,700 / y=2,300〜5,300`

中心：**ネメリア** `(5,200,3,800)`

- 密度の高い森林、林間草地、小川、低い丘陵。
- 西岸は入り江と崖が多く、海沿いは直進しにくい。
- 森の内部には古道、倒木、細い沢などを配置できる。
- ネメリアは猟師・薬草師・木工職人が森と共生して暮らす町。
- 住民の多くは森の精霊の存在を信じている。

## 3. 中央草原・エルド周辺

**おおよその範囲：** `x=6,300〜9,700 / y=3,000〜5,300`

中心：**エルド** `(8,000,4,200)`

- 草原、低い丘、農地、小さな林、浅い川。
- 主島でもっとも歩きやすい地域。
- 複数の街道が集まる交通結節点。
- 序盤の基準エリアとして、初期カード、依頼、探索チュートリアルを配置しやすい。

## 4. 北東高原地帯

**おおよその範囲：** `x=9,500〜12,400 / y=2,300〜4,700`

中心：**アウロス** `(10,700,3,700)`

- 開けた高原、草地、低い岩山、峡谷の入口。
- 一年を通して風が強い。
- アウロスは牧畜を中心に発展し、乳製品・毛織物・革製品が生活と交易に関わる。
- 風向き、雲、星空などを読む知識が生活文化として発達している。

## 5. 南西湖沼・湿地地帯

**おおよその範囲：** `x=3,700〜7,600 / y=4,900〜7,400`

中心：**ネレム** `(6,000,6,100)`

- 大小の湖、湿地、葦原、浅い川、島状の乾いた土地。
- 湿地特有の独自生態系が成立している。
- ネレムは水上に形成された木造都市で、木道・桟橋・小橋・水路・小舟が生活の一部。
- 水位・季節・天候・時間帯によって探索条件や生物相が変化する地域として扱う。

## 6. 東部荒野・岩山地帯

**おおよその範囲：** `x=9,700〜13,000 / y=3,800〜7,200`

中心：**モルグレイ** `(11,200,6,100)`

- 乾燥地、岩山、峡谷、砂礫地、荒れた海岸。
- 見通しは良いが、崖や峡谷で進路を曲げられる。
- モルグレイは「世界から捨てられたものが集まる場所」。再利用・修理・独自の共同体文化が強い。

## 7. 中央南部・港湾平原

**おおよその範囲：** `x=6,700〜10,700 / y=5,000〜8,200`

中心：**ヴェルノク** `(8,500,5,500)`、**マレスタ** `(8,600,7,700)`

- ヴェルノク周辺は平野、農地、河川。
- 南へ行くほど丘陵と海岸地形が増え、港湾半島へ続く。
- ヴェルノクは主島最大都市で、交通・商業・情報・権力の中心。
- マレスタは周辺島への交通拠点で、魚介の集積・流通拠点でもある。

# 補助ルート・探索路

- ネメリア周辺の旧道・獣道
- カルドラント周辺の峠道
- アウロスから北山へ抜ける細道
- ネレム周辺の木道・浅瀬ルート
- 中央草原の農道
- モルグレイ周辺の峡谷道
- 海岸沿いの行き止まり道
- 廃道、崩れた橋、洞窟経由のショートカット
- スカルドと主島北部山岳地帯を結ぶ隠れたルート（存在のみ確定）

補助ルートは「近道」だけでなく、カード・NPC・依頼・遺跡・観察地点へ向かう探索導線として使う。

# 街道設計のルール

- 主要街道だけを歩けば主島8都市へ到達できる。
- ただし、主要街道だけではワールドのカードや探索地点の大半には触れない。
- 道を外れたくなる視覚的な誘因を置く。例：遠くの塔、煙、滝、光、奇妙な樹木、崖上の建物。
- 一本道が長く続かないよう、30〜60秒程度の移動ごとに分岐、地形変化、ランドマーク、探索候補のいずれかを入れることを目安にする。
- 一本道を長く引き延ばして移動時間を稼がない。

# 現時点で確定するもの

- 主島を7つの主要地形エリアに分ける。
- 各エリアの大まかな位置関係と役割。
- 上記8系統の主要街道。
- 主島8都市の正式名称と基準座標。
- スカルドと主島北部山岳地帯を結ぶ隠れたルートの存在。

# 後から調整できるもの

- 各街道の細かなカーブと道幅。
- 補助ルートの正確な入口・出口。
- 各エリアの詳細境界。
- スカルドへつながる隠れたルートの構造・入口・発見条件。
- 危険度、敵対生物、季節・天候による移動差。
