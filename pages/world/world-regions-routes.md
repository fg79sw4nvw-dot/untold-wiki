# 主島エリア分け・街道

完成版ワールドデータ **v11** を基準にした、主島・周辺島の地形、水系、街道ネットワーク。

目的は、見た目上の地域差だけでなく、**実際にプレイヤーが歩いて探索することを前提にした移動構造**を作ること。

## 基本仕様

- ワールドサイズ：`16000 × 10000px`
- 地形判定セル：`64 × 64px`
- グリッド：`250 × 157`（39,250セル）
- 地形ID：
  - `0` 草原
  - `1` 森林
  - `2` 山岳
  - `3` 高原
  - `4` 湿地
  - `5` 荒野
  - `6` 海岸
  - `7` 海・川・湖
- 海・川・湖は同じ水域地形 `7` として扱う。
- 海岸線ポリゴンは保持しない。主島・周辺島の輪郭は不規則な暗黙形状から生成する。
- 地形境界は直線で区切らず、山裾、川、植生、地表色などに沿って自然に蛇行する。
- 本島内部の小さな飛び地、1〜2セル級の不自然な突起は完成版で整理済み。
- スカルド、サヴェリア、無人島A/B/Cは主島から完全に分離した島として扱う。

# 主島の主要地形

## 1. 北部山岳地帯

中心：**カルドラント** `(8,000,2,000)`

- 主島最高峰を含む雪山・岩山・高地草原。
- 山脈は東西方向へ広がり、西部森林側と北東高原側へ自然に張り出す。
- 南側へ複数の尾根が伸びる。
- 完全な壁にはせず、主要な山道と細い峠道を持つ。
- 北へ行くほど積雪・寒冷の影響が強い。
- カルドラントは鉱山都市で、周辺の鉱石・金属資源と鍛冶文化を基盤に発展している。
- スカルドからこの山岳地帯へつながる、外からは分かりにくいルートが存在する。構造・入口・発見条件は未確定。

## 2. 西部大森林

中心：**ネメリア** `(5,200,3,800)`

- 密度の高い森林、林間草地、小川、低い丘陵。
- 西岸は入り江と崖が多く、海沿いは直進しにくい。
- 北部では山岳地帯と自然に接続する。
- 東側の一部は西中央川を境に中央草原へ切り替わる。
- ネメリアは猟師・薬草師・木工職人が森と共生して暮らす町。

## 3. 中央草原・エルド周辺

中心：**エルド** `(8,000,4,200)`

- 草原、低い丘、農地、小さな林、浅い川。
- 主島でもっとも歩きやすい地域。
- 複数の街道が集まる交通結節点。
- 西中央川の東側が草原との主要境界のひとつになる。
- 北は山岳、北東は高原、東は荒野へ自然に遷移する。

## 4. 北東高原地帯

中心：**アウロス** `(10,700,3,700)`

- 開けた高原、草地、低い岩山、峡谷の入口。
- 一年を通して風が強い。
- 完成版では従来案より南・東へ拡大し、荒野との境界を南側へ下げている。
- 西側では北部山岳と蛇行した境界で接続する。
- アウロスは牧畜を中心に発展し、乳製品・毛織物・革製品が生活と交易に関わる。

## 5. 南西湖沼・湿地地帯

中心：**ネレム** `(6,000,6,100)`

- 翠の湖、小湖、湿地、葦原、浅い川、島状の乾いた土地。
- 西中央川下流と南流川が中央草原との主要な地形境界になる。
- 湿地特有の独自生態系が成立している。
- ネレムは水上に形成された木造都市で、木道・桟橋・小橋・水路・小舟が生活の一部。
- 水位・季節・天候・時間帯によって探索条件や生物相が変化する地域として扱う。

## 6. 東部荒野・岩山地帯

中心：**モルグレイ** `(11,200,6,100)`

- 乾燥地、岩山、峡谷、砂礫地、荒れた海岸。
- 北側は高原と接し、完成版では高原拡大により荒野は南東寄りにまとまる。
- 見通しは良いが、崖や峡谷で進路を曲げられる。
- モルグレイ周辺そのものは荒野として維持する。

## 7. 中央南部・港湾平原

中心：**ヴェルノク** `(8,500,5,500)`、**マレスタ** `(8,600,7,700)`

- ヴェルノク周辺は平野、農地、河川。
- 南へ行くほど丘陵と海岸地形が増え、港湾部へ続く。
- マレスタは南岸の海岸線に隣接する港町として配置する。
- 南流川は南西湿地と中央南部草原の境界を作り、そのままマレスタ側の外海へ接続する。
- ヴェルノクは主島最大都市で、交通・商業・情報・権力の中心。
- マレスタは周辺島への交通拠点で、魚介の集積・流通拠点でもある。

# 水系

## 西中央川

上流から西部森林と中央草原の境界を流れ、下流では南西湿地と中央草原の境界になる。

主要アンカー：

`(6900,2750) → (6750,3150) → (7000,3500) → (6930,3800) → (6850,4000) → (6720,4300) → (6600,4450) → (6500,4900) → (6350,5200) → (6250,5400) → (6100,5600) → (6000,5750)`

終端は翠の湖へ接続する。

## 南流川

翠の湖から南東へ流れ、南西湿地と中央南部草原の境界を形成し、最終的にマレスタ側の外海へ接続する。

主要アンカー：

`(6250,6050) → (6500,6200) → (6850,6450) → (7200,6700) → (7420,6820) → (7550,6900) → (7900,7200) → (8150,7550) → (8250,7900) → (8400,8200) → (8600,8450)`

## 削除済み水系

- 東高原川は完成版では削除する。
- 東側に存在していた閉鎖水域は削除する。
- 小湖東 `(6700,5750)` は削除する。

# 周辺島

- **スカルド** `(5,000,1,700)` は主島と完全に分離した北西の島。
- **サヴェリア** `(14,600,5,800)` は東方の独立島。
- 無人島A/B/Cも主島とは接続しない。
- 島の輪郭は単純な円・楕円ではなく、湾、岬、切れ込みを持つ不規則な自然地形として生成する。
- スカルドと主島北部山岳地帯を結ぶ隠れたルートの存在は維持する。構造・入口・発見条件は未確定。

# 街道設計のルール

- 主要街道だけを歩けば主島8都市へ到達できる。
- ただし、主要街道だけではワールドのカードや探索地点の大半には触れない。
- 町と町を最短距離の直線だけで結ばない。
- 一本道が長く続かないよう、30〜60秒程度の移動ごとに分岐、地形変化、ランドマーク、探索候補のいずれかを入れることを目安にする。
- 道を外れたくなる視覚的な誘因を置く。例：遠くの塔、煙、滝、光、奇妙な樹木、崖上の建物。
- 補助ルートとして旧道、獣道、峠道、農道、木道、峡谷道、廃道、洞窟経由のショートカットを配置できる。

# 完成版として確定するもの

- ワールドサイズ `16000 × 10000px`。
- 64×64pxセルによる8地形の共通地形レイヤー。
- 完成版v11の主島・周辺島の輪郭と地形割り当て。
- 各町・島の基準座標。
- 西中央川、南流川、翠の湖、小湖2つ。
- 東高原川、東側閉鎖水域、小湖東の削除。
- 上記8系統の主要街道。
- ネレム→マレスタの南西街道の削除。
- BR-01〜BR-03の3橋。
- 地形境界を直線ではなく自然な蛇行・川・山裾で構成する方針。
- 不自然な小さな飛び地や点在地形を除去したv11の地形配置を完成版とする。

# 後から調整できるもの

- 各街道の道幅と細かなカーブ。
- 補助ルートの正確な入口・出口。
- 地形の見た目用タイル・オブジェクト配置。
- スカルドへつながる隠れたルートの構造・入口・発見条件。
- 危険度、敵対生物、季節・天候による移動差。
