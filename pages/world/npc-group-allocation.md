# 都市別・主要NPC群配分

このページは、オルバ10都市に置く**常設・会話可能NPCのD2段階の役割群、人数構成、主な配置方針**を扱う横断正本。

個々の名前、性別、年齢、外見、性格、台詞、依頼、カード対象、詳細な知識状態はD4で確定する。

## 共通原則【D2確定】

- 各都市の会話可能NPC総数は `pages/world/towns.md` の確定値を変えない。
- NPC群は、D4で個人を設計するための**役割枠**であり、全員を同じ職業・性格に固定するものではない。
- 一人のNPCが複数の生活役割を持つことは許容するが、人数管理上は一つの主群へ所属させる。
- 主要情報は「真相を知る人」へ集中させず、生活圏・職業・経験に応じて断片的に分散する。
- 各都市に、少なくとも以下の3種類の情報源を置ける構成を保つ。
  1. 現在の生活・地域知識
  2. 地域の過去・口伝・物の由来
  3. 旅人・物流・他地域との接点
- 背景群衆、通行人、一時イベントNPCはこの人数に含めない。
- D2では群と配置までを固定し、誰が重要人物・カード対象になるかはD4で決める。

# D4への受け渡しルール

個別NPCを作る際は、以下の順で空き枠を消費する。

1. 都市と主NPC群を決める。
2. その群でまだ不足している生活役割を確認する。
3. 個人の職業・立場・性格・知識状態を設定する。
4. 情報ネットワーク、依頼、カード、人物関係が必要な場合だけ接続する。
5. 「物語上必要だから職業を後付けする」のではなく、その町で普通に暮らしている人物として成立させる。

- D4で人物カード対象や主要イベント人物を追加しても、原則として各都市の会話可能NPC総数の内側で割り当てる。
- 総数を変更する必要が出た場合は、個別追加で黙って増やさず `pages/world/towns.md` の人口・NPC配分と合わせて再評価する。
