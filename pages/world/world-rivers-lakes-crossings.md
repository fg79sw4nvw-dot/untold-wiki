# 主島の川・湖・橋・山岳横断

主島の確定ワールド座標、7エリア、主要街道を前提にした移動障害の配置。

## 基本ルール【確定】

- 川は徒歩では渡れない。
- 湖は徒歩では入れない・横断できない。
- 山岳の急斜面・稜線は徒歩では越えられない。
- 峠周辺も自由横断はできず、整備された峠道・岩門・洞道など、明示された横断ルートだけを通れる。
- 川を渡れるのは橋などの明示された横断地点だけ。
- 水泳で強引にショートカットする移動は採用しない。
- 主要街道を使えば主島8都市すべてへ到達できる。

# 水系

## 1. 西中央川

北部山岳南西斜面から西部森林と中央草原の境界を流れ、南西湖沼へ注ぐ主河川。

```text
WEST_CENTRAL_RIVER = [
  (6900, 2750),
  (6750, 3150),
  (7000, 3500),
  (6850, 4000),
  (6600, 4450),
  (6500, 4900),
  (6250, 5300),
  (6100, 5600)
]
```

- ネメリアとエルドを完全に分断する壁にはしない。
- 西街道は橋を1回渡ることで自然に曲がる。
- 下流へ行くほど湿地化し、ネレム周辺の湖沼景観へつながる。

## 2. 東高原川

北東高原から東部荒野へ流れ、南東海岸へ抜ける河川。

```text
EAST_HIGHLAND_RIVER = [
  (10100, 2850),
  (10350, 3350),
  (10150, 3850),
  (10400, 4300),
  (10650, 4750),
  (10550, 5200),
  (10900, 5650),
  (11300, 6100),
  (11700, 6550)
]
```

- アウロスからモルグレイへ向かう道を少し蛇行させる。
- ヴェルノクからモルグレイへ向かう交易路にも横断点を作る。
- 東部は崖と川を組み合わせ、見通しは良いのに真っ直ぐ進めない地形にする。

## 3. 南流川

南西湖沼の水を受け、中央南部を通って南岸へ流れる川。

```text
SOUTH_RIVER = [
  (6500, 6200),
  (6850, 6450),
  (7200, 6700),
  (7550, 6900),
  (7900, 7200),
  (8150, 7550),
  (8100, 7900)
]
```

- ネレムからマレスタへ向かう南西街道に1回の橋渡りを要求する。
- ヴェルノクからマレスタへの幹線は川の東側を基本にし、必要以上に橋だらけにしない。

# 湖

## 翠の湖【主湖】

南西湖沼地帯の中心となる大きな湖。名称は現時点では仮称。

```text
EMERALD_LAKE = [
  (5200, 5350),
  (5550, 5150),
  (6000, 5200),
  (6350, 5450),
  (6450, 5800),
  (6250, 6050),
  (5900, 6150),
  (5500, 6050),
  (5200, 5750)
]
```

**ネレム** `(6000,6100)` は湖の南岸〜南東岸に接する位置関係とする。

- 湖そのものは横断不可。
- 北岸はネメリア・ヴェルノク方面へ便利。
- 南岸はマレスタ方面へ便利。
- 湖周辺には湿地独自の生態系が成立し、ネレムの生活・探索・カード条件と強く結びつく。

## 小湖群

主湖の西〜南西に小さな湖を2〜3個置く。

- 小湖北：`(4700,5600)`
- 小湖南：`(5000,6400)`
- 小湖東：`(6700,5750)`

# 北部山岳と横断ルート

おおよその障壁帯：

```text
x = 6200〜10000
y = 1200〜3200
```

## M-01 中央峠道

基準点：`(8,000,3,000)`

- **カルドラント ↔ エルド**を結ぶ主ルート。
- 最も分かりやすく、安全性も比較的高い。
- 中央縦断街道の一部。

## M-02 西岩門

基準点：`(6,450,2,950)`

- 西部大森林から北部山岳へ抜ける補助ルート。
- ネメリア方面からカルドラントへ向かう遠回りルートとして機能。

## M-03 東峠道

基準点：`(9,650,3,000)`

- アウロス側から北部山岳へ入る補助ルート。
- アウロスとカルドラントの間に別経路を与える。

## スカルド接続ルート

- **スカルドから主島北部山岳地帯へつながる隠れたルートが存在することは確定。**
- 通常のM-01〜M-03とは別枠で扱う。
- 洞窟、地下道、天然の岩道など具体的な構造は未確定。
- 主島側の入口・スカルド側の入口・発見条件も未確定。
- 一見して分かる通常航路や一般街道にはしない。

# 移動バランス

- 中央草原は比較的自由に歩ける。
- 西へ行くと川と森林でルート選択が増える。
- 南西へ行くと湖と湿地が大きなランドマーク兼障害物になる。
- 東へ行くと川と崖によって直線移動が崩れる。
- 北へ行くと山岳横断点を意識する必要がある。
- マレスタへは比較的分かりやすく到達できる。

# 現時点で確定するもの

- 川・湖は徒歩横断不可。
- 山岳の急斜面・稜線は徒歩横断不可。
- 西中央川・東高原川・南流川の3河川。
- 翠の湖を主島最大の湖とする。
- BR-01〜BR-06の6橋を主要橋の基準位置とする。
- M-01〜M-03の3つを北部山岳の基本横断ルートとする。
- スカルドから主島北部山岳地帯へつながる隠れたルートの存在。

# 後から調整できるもの

- 川幅・湖岸線の細部。
- 橋の見た目、名称、材質。
- 小湖群の正確な外形。
- 峠道内のカーブ、洞窟、見晴台、探索枝。
- 雨や季節による水位変化の具体値。
- スカルド接続ルートの構造・入口・発見条件。
