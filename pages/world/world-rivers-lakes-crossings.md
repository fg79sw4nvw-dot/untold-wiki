# 主島の川・湖・橋・山岳横断

確定基礎地形マスク `assets/elden-terrain-mask-final.svg` を前提にした移動障害の整理。

## 基本ルール【確定】

- 川は徒歩では渡れない。
- 湖・湖沼は徒歩では入れない・横断できない。
- 水泳で強引にショートカットする移動は採用しない。
- 川を渡れるのは橋などの明示された横断地点だけ。
- 山岳の急斜面・稜線は徒歩では越えられない。
- 峠周辺も自由横断はできず、整備された峠道・岩門・洞道など、明示された横断ルートだけを通れる。
- 主要街道を使えば主島8都市すべてへ到達できる設計とする。

# 水系【確定基礎形状】

水域の正確な大形状は、ワールドマップの確定基礎地形マスクを正とする。

## 主河川

- 主島北部寄りから南方向へ流れる一本の主要河川を基礎とする。
- 中流域で南西部の湖沼水系と接続する。
- その後さらに南へ流れ、**マレスタの西側から南岸の海へ流れ込む**。
- 河川形状は比較的シンプルな蛇行とする。
- 旧案のように主島を単純に縦断する一直線的な水系にはしない。

## 南西湖沼水系

- ネレム周辺の南西部には、複数の湖・湖沼が連なる水域を置く。
- ネレムは湖沼地帯と密接に結びつく水上・湿地都市として扱う。
- 湖沼群の細かな名称、個別の湖の境界、湿地との境界は未確定。
- 最北側に独立していた湖は削除済みで、確定基礎マスクには含めない。

## 旧水系仕様の扱い

以前設定していた以下の固定仕様は、確定基礎地形マスクの採用に伴い**廃止・再設計対象**とする。

- 西中央川・東高原川・南流川の3河川構成。
- 各河川の旧座標列。
- 翠の湖の旧ポリゴン座標。
- 小湖群の旧固定座標。

今後は、基礎地形マスクを崩さない範囲で必要な支流・湿地・細水路を追加する。

# 橋【基本仕様確定】

旧 `BR-01`〜`BR-06` の6橋座標は、旧3河川構成を前提としていたため**固定仕様から外す**。

## 橋の共通仕様

- 橋は通常橋の**1種類のみ**とし、壊れた橋・特殊橋などの別カテゴリは当面設けない。
- 橋は固定配置で、壊れない・消えない・条件なしで常時通行可能とする。
- 橋の下にある地形IDは**川／内陸水域のまま変更しない**。
- 徒歩通行可否だけを橋オブジェクト／地点別オーバーライドで上書きする。
- 橋上でも通常どおりエンカウント判定を行い、橋だからエンカウントを無効化する処理は入れない。
- 橋の**通行可能幅は96px**を基準とする。
- 見た目上の橋幅は**100〜110px前後**を基準とする。
- 橋の長さは横断する川幅に応じて可変とする。

## 主島の基本3橋【本数・接続先確定】

当面の主要橋は**3本**とする。

1. **ネメリア ↔ エルド導線の橋**
2. **ネレム ↔ ヴェルノク導線の橋**
3. **ネレム ↔ マレスタ導線の橋**

- ヴェルノク ↔ マレスタ間には現時点で追加の主要橋を置かない。
- 3本の橋は、橋座標を先に決めるのではなく、**各都市間の主要街道ルートを先に設計し、その街道と河川・水域が交差する地点を橋位置として決める**。
- 街道は単純な最短直線ではなく、地形・湿地・湖沼・河川を自然に避ける導線とする。
- 特にネレム周辺は湿地・湖沼による迂回を許容し、土地の特徴が移動経路に表れる設計とする。

橋の正確な座標・名称・材質・外観デザインは、3本の街道ルート確定後に決める。

# 北部山岳と横断ルート

おおよその障壁帯は引き続き北部山岳地帯として扱う。

## M-01 中央峠道

- **カルドラント ↔ エルド**を結ぶ主ルート。
- 最も分かりやすく、安全性も比較的高い。
- 中央縦断街道の一部。

## M-02 西岩門

- 西部大森林から北部山岳へ抜ける補助ルート。
- ネメリア方面からカルドラントへ向かう遠回りルートとして機能。

## M-03 東峠道

- アウロス側から北部山岳へ入る補助ルート。
- アウロスとカルドラントの間に別経路を与える。

## スカルド接続ルート

- **スカルドから主島北部山岳地帯へつながる隠れたルートが存在することは確定。**
- 通常のM-01〜M-03とは別枠で扱う。
- 洞窟、地下道、天然の岩道など具体的な構造は未確定。
- 主島側の入口・スカルド側の入口・発見条件も未確定。
- 一見して分かる通常航路や一般街道にはしない。

# 移動バランス

- 中央部は比較的自由に歩ける。
- 西〜南西へ行くと湖沼と主河川によってルート選択が増える。
- ネレム周辺では湖沼・湿地が大きなランドマーク兼障害物になる。
- マレスタ西側には河口があり、港湾地形や街道設計に影響する。
- 北へ行くと山岳横断点を意識する必要がある。

# 現時点で確定するもの

- 川・湖・湖沼は徒歩横断不可。
- 山岳の急斜面・稜線は徒歩横断不可。
- 水系の大形状は確定基礎地形マスクを正とする。
- 主河川は北部寄りから南西湖沼水系へつながり、マレスタ西側から南岸の海へ流れ込む。
- 旧3河川構成と旧橋座標は廃止し、基礎マスクに合わせて再設計する。
- 橋は通常橋1種類、固定配置、常時通行可、川地形IDを維持し通行のみ上書きする。
- 橋上でも通常エンカウントを行う。
- 橋の通行可能幅96px、見た目の幅100〜110px前後を基準とする。
- 主要橋はネメリア↔エルド、ネレム↔ヴェルノク、ネレム↔マレスタの3本とする。
- 橋位置は街道ルートを先に決め、その交差地点として確定する。
- M-01〜M-03の3つを北部山岳の基本横断ルートとする。
- スカルドから主島北部山岳地帯へつながる隠れたルートの存在。

# 後から決めるもの

- 河川名。
- 川幅、支流、細水路。
- 湖沼群の個別名称と湿地境界。
- 3本の街道ルートの具体形状。
- 3本の橋の正確な座標・名称・材質・外観デザイン。
- 峠道内のカーブ、洞窟、見晴台、探索枝。
- 雨や季節による水位変化の具体値。
- スカルド接続ルートの構造・入口・発見条件。
