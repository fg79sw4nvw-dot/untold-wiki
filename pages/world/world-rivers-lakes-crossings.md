# 主島のナーヴァ水系・街道・橋・山岳横断

確定基礎地形マスク `assets/elden-terrain-mask-final.svg` を前提にした移動障害・主要街道・橋の整理。

> **現行仕様の優先順位**
> 本ページの街道・橋・水系仕様を現行仕様として扱う。`pages/world/world-regions-routes.md` や `assets/world-map-v11-rle.json` に残る旧街道・旧河川・旧橋座標と矛盾する場合は、本ページと確定基礎地形マスクを優先する。

## 基本ルール【確定】

- 川は徒歩では渡れない。
- 湖・湖沼は徒歩では入れない・横断できない。
- 水泳で強引にショートカットする移動は採用しない。
- 川を渡れるのは橋などの明示された横断地点だけ。
- 山岳の急斜面・稜線は徒歩では越えられない。
- 峠周辺も自由横断はできず、整備された峠道・岩門・洞道など、明示された横断ルートだけを通れる。
- 主要街道を使えば主島8都市すべてへ到達できる設計とする。
- 主島の交通網はレグナだけを中心とする放射状ではなく、複数の迂回・地域間接続を持つ**網状交通**とする。
- 都市のワールド基準座標は地理上の代表点であり、すべての街道が物理的にその一点へ交差することを意味しない。都市内部の門・入口へ複数方向から接続してよい。

# ナーヴァ水系【確定】

主島の河川・湖・湖沼を含む内陸水域全体の固有地理名を **ナーヴァ水系** とする。水域の正確な大形状は、ワールドマップの確定基礎地形マスクを正とする。

## 主河川：ナーヴァ川【確定】

- 主島北部寄りから南方向へ流れる一本の主要河川の正式名称を **ナーヴァ川** とする。
- **ナーヴァ水系**という呼称は、この主河川と接続する湖沼・細水路をまとめた水系名として使用する。
- 中流域で南西部の湖沼水系と接続する。
- その後さらに南へ流れ、**ポルトナの西側から南岸の海へ流れ込む**。
- 河川形状は比較的シンプルな蛇行とする。
- 旧案のように主島を単純に縦断する一直線的な水系にはしない。

### 川幅【確定】

ワールド上の見た目・通行障害としての基準幅は、区間によって変化させる。

- 上流〜中流：概ね **80〜130px**。
- 湖沼接続部周辺：概ね **90〜150px**。湿地・浅瀬表現によって水際は不規則にする。
- 下流〜河口側：概ね **150〜240px**。ポルトナ西側の河口へ近づくほど広がる。
- 橋地点では確定済みの実測水面横断長を優先する。
- 川幅を全区間で一定にはしないが、局所的な細り・広がりのために確定基礎地形マスクの大形状を変更しない。

## 支流・細水路【確定】

- ワールドマップ規模でナーヴァ川に並ぶ**別の大河・主要支流は追加しない**。
- 南西湖沼水系とミオ湿原では、湖同士・湿地・ナーヴァ川をつなぐ細水路や浅い流れを複数持つ。
- 細水路はリュメイ周辺の生活、採取、湿地景観、水路移動等へ使えるが、すべてへ固有名を付けない。
- ワールド規模の主要通行障害として扱う水域は、確定基礎地形マスク上の地形ID `6` を正とする。
- 地域内部の細い水路・季節的なぬかるみ・葦原内の流れは、個別都市・地域マップ側のサブ地形として表現してよい。

## 南西湖沼水系【確定】

- リュメイ周辺の南西部には、複数の湖・湖沼が連なる水域を置く。
- リュメイは湖沼地帯と密接に結びつく水上・湿地都市として扱う。
- 湖沼を地図上のすべての水面ごとに細分して命名する方式にはしない。
- 現在の生活圏で主要な開水面だけを固有名で呼び、小さな池・沼・浅水域はまとめて地域呼称で扱う。

### リュメイ湖【確定】

- リュメイの市街・生活圏と最も直接につながる主要湖。
- 舟運、漁、採取、町の景観上の基準となる水面。
- 「リュメイ」という町名と湖名のどちらが先か、厳密な語源関係は固定しない。

### ユラ湖【確定】

- リュメイ湖より南〜南東側に位置する主要な開水面の呼称。
- リュメイ ↔ ポルトナ方面の陸地回廊や湿地景観を形作る水域の一つとして扱う。
- リュメイ湖ほど都市生活へ直接組み込まれておらず、湿地・採取・野生生物との関係を強める。

### ミオ沼群【確定】

- リュメイ湖・ユラ湖の周囲に点在する小湖沼、浅水域、葦原内の水面をまとめた地域呼称。
- 一つの巨大な湖の正式名称ではない。
- 個々の小沼へ原則として固有名を付けず、依頼・カード等で必要になった場合だけD4で局所名を追加する。

## ミオ湿原との境界【確定】

- システム上、恒常的な開水面・湖・川は地形ID `6` の**ナーヴァ水系**、歩行可能な湿地・葦原・ぬかるみは地形ID `4` の**ミオ湿原**として区別する。
- 世界内の景観上は、水際の葦原、湿った草地、浅瀬が連続するため、境界を人工的な一本線として見せない。
- 地域マップでは「水面か地面か」という通行判定は明確に保ちつつ、見た目は緩やかに移行させる。
- 季節・天候で水面そのものの確定ワールド形状が大きく変わるシステムにはしない。

## 旧水系仕様の扱い

以前設定していた以下の固定仕様は、確定基礎地形マスクの採用に伴い**廃止**とする。

- 西中央川・東高原川・南流川の3河川構成。
- 各河川の旧座標列。
- 翠の湖の旧ポリゴン座標。
- 小湖群の旧固定座標。

# 主要街道【10本確定】

主要街道は、町同士を最短直線だけで結ばず、地形・湿地・湖沼・河川・山岳に加えて、各都市の産業・生活・交易関係を踏まえて設計する。

# 橋【3本・名称・位置・寸法・外観確定】

旧 `BR-01`〜`BR-06` の6橋座標は、旧3河川構成を前提としていたため**固定仕様から外す**。

## 橋の共通仕様【確定】

- 橋は通常橋の**1種類のみ**とし、壊れた橋・特殊橋などの別カテゴリは当面設けない。
- 橋は固定配置で、壊れない・消えない・条件なしで常時通行可能とする。
- 橋の下にある地形IDは**川／内陸水域のまま変更しない**。
- 徒歩通行可否だけを橋オブジェクト／地点別オーバーライドで上書きする。
- 橋上でも通常どおりエンカウント判定を行い、橋だからエンカウントを無効化する処理は入れない。
- 橋の**通行可能幅は96px**を基準とする。
- 見た目上の橋幅は**100〜110px前後**を基準とする。
- 橋の長さは横断する川幅に応じて可変とする。
- 3橋は同一カテゴリだが、周辺地域の資材・交通量に応じて外観差を持たせる。

## 森口橋：オルメド ↔ エルド【確定】

- 旧管理呼称：主要橋1。
- 西岸：約 `(6465,4146)`
- 東岸：約 `(6570,4188)`
- 中心：約 `(6518,4167)`
- 水面横断長：約 `113px`
- 東進時の向き：約 `22°` 南向き
- 両岸への掛かりを各約30px取った見た目上の全長：約 `170px`
- 通行可能幅：`96px`
- 見た目幅：`100〜110px前後`
- 正式名称：**森口橋**。
- ネモラ大森林側からカナタ平原・エルド地方へ抜ける「森の口」に位置することから生じた実用的な呼称とする。
- 石積みの橋台に、太い木材を組んだ桁・床板を載せる構造。
- オルメド側の豊富な木材を感じさせるが、全面木造の簡素な橋にはせず、主要街道として十分な耐久性を持たせる。
- 外観はやや暗い木材、低めの木柵、両岸の石積みを基調とする。

- ミオ湿原・湖沼側の葦原を抜けて渡る生活感のある地名として扱う。

- 湿地側の取付部は短い木道・盛土へ自然につなげる。
- 水位や湿地環境を読むための簡素な目印・杭を景観として置いてよいが、橋自体を可動・条件式にはしない。

## 河口橋：リュメイ ↔ ポルトナ【確定】

- 旧管理呼称：主要橋3。
- 西岸：約 `(7447,7609)`
- 東岸：約 `(7671,7591)`
- 中心：約 `(7559,7600)`
- 水面横断長：約 `224px`
- 東進時の向き：約 `4°` 北向き
- 両岸への掛かりを各約30px取った見た目上の全長：約 `284px`
- 通行可能幅：`96px`
- 見た目幅：`100〜110px前後`
- 正式名称：**河口橋**。
- ナーヴァ川が南岸へ開く下流域に位置する、3橋中もっとも長い橋。
- 複数の石造橋脚に木製桁・床板を渡す多径間構造とし、長い一枚橋にはしない。
- ポルトナ方面の物流を支えるため、3橋の中では最も規則的に補修されている外観にする。
- 船舶用の巨大可動橋にはせず、河口西側の陸上物流路を安定して通す橋として扱う。

- レグナ ↔ ポルトナ間には追加の主要橋を置かない。

# 北部山岳と横断ルート【確定】

おおよその障壁帯は引き続き**カンデル山脈**として扱う。

## M-01 中央峠道【具体ルート確定】

- **カルドラント ↔ エルド**を結ぶ主ルート。
- 最も分かりやすく、安全性も比較的高い。
- 中央縦断街道の一部。
- 具体アンカーは「主要街道 4. カルドラント ↔ エルド」を正とする。

## M-02 西岩門【具体ルート・名称確定】

アンカーポイント：

`(5200,3800) → (5350,3500) → (5650,3200) → (6000,2950) → (6400,2700) → (6850,2500) → (7250,2380) → (7500,2280) → (7600,2200)`

- ネモラ大森林からカンデル山脈へ抜ける補助山岳路。
- `(7600,2200)` でM-01へ合流し、カルドラントまでM-01を共用する。
- M-01より狭く険しく、大型荷車の常用には向かない。
- オルメドの猟師・薬草師など森林・山岳に慣れた人が利用しやすい短絡路として扱う。
- `(6850,2500)`〜`(7250,2380)` 周辺では、自然の岩壁の切れ目を通る狭い通過地形を基礎イメージとする。
- **西岩門**は、この狭い岩壁の切れ目とそこを通る道をまとめて指す現在の一般呼称として正式採用する。

## M-03 東峠道【具体ルート・名称確定】

アンカーポイント：

`(8000,2000) → (8350,2050) → (8750,2200) → (9100,2400) → (9400,2650) → (9700,2950) → (9950,3250) → (10250,3500) → (10700,3700)`

- カルドラントからカンデル山脈東側を抜け、フウラ高原・ハルクァへ至る補助山岳交易路。
- M-01より狭く、主要幹線の代替ではなく地域を知る者が使う短絡路。
- 山岳から風の強い高原へ視界が開ける地形変化を特徴とする。
- ハルクァ側では季節的な放牧路へ枝分かれし得るが、それらはM-03本線には含めない。
- **東峠道**は現在の一般呼称として正式採用する。

## D-01 古渡り坑／スカルド接続【具体構造確定】

- ブリガン島の町スカルド方面と、主島北部・カンデル山脈を結ぶ隠れた接続は D-01 **古渡り坑**とする。

- 現在は坑道全体が両地域を結ぶという知識が失われており、探索によって接続を再発見する。
- 具体的な起源、両側入口、発見経路、内部構造、踏破後の扱いは `pages/world/old-crossing-mine.md` を正本とする。
