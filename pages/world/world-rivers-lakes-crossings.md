# 主島のナーヴァ水系・街道・橋・山岳横断

確定基礎地形マスク `assets/elden-terrain-mask-final.svg` を前提にした移動障害・主要街道・橋の整理。

> **現行仕様の優先順位**
> 本ページの街道・橋・水系仕様を現行仕様として扱う。`pages/world/world-regions-routes.md` や `assets/world-map-v11-rle.json` に残る旧街道・旧河川・旧橋座標と矛盾する場合は、本ページと確定基礎地形マスクを優先する。

## 基本ルール【確定】

- 川は徒歩では渡れない。
- 湖・湖沼は徒歩では入れない・横断できない。
- 水泳で強引にショートカットする移動は採用しない。
- 川を渡れるのは橋などの明示された横断地点だけ。
- 山岳の急斜面・稜線は徒歩では越えられない。
- 峠周辺も自由横断はできず、整備された峠道・岩門・洞道など、明示された横断ルートだけを通れる。
- 主要街道を使えば主島8都市すべてへ到達できる設計とする。
- 主島の交通網はレグナだけを中心とする放射状ではなく、複数の迂回・地域間接続を持つ**網状交通**とする。
- 都市のワールド基準座標は地理上の代表点であり、すべての街道が物理的にその一点へ交差することを意味しない。都市内部の門・入口へ複数方向から接続してよい。

# ナーヴァ水系【確定基礎形状】

主島の河川・湖・湖沼を含む内陸水域全体の固有地理名を **ナーヴァ水系** とする。水域の正確な大形状は、ワールドマップの確定基礎地形マスクを正とする。

## 主河川

- 主島北部寄りから南方向へ流れる一本の主要河川を基礎とする。
- 中流域で南西部の湖沼水系と接続する。
- その後さらに南へ流れ、**ポルトナの西側から南岸の海へ流れ込む**。
- 河川形状は比較的シンプルな蛇行とする。
- 主河川そのものの個別名称は未確定。
- 旧案のように主島を単純に縦断する一直線的な水系にはしない。

## 南西湖沼水系

- リュメイ周辺の南西部には、複数の湖・湖沼が連なる水域を置く。
- リュメイは湖沼地帯と密接に結びつく水上・湿地都市として扱う。
- 湖沼群の細かな名称、個別の湖の境界、ミオ湿原との細かな境界は未確定。
- 最北側に独立していた湖は削除済みで、確定基礎マスクには含めない。

## 旧水系仕様の扱い

以前設定していた以下の固定仕様は、確定基礎地形マスクの採用に伴い**廃止・再設計対象**とする。

- 西中央川・東高原川・南流川の3河川構成。
- 各河川の旧座標列。
- 翠の湖の旧ポリゴン座標。
- 小湖群の旧固定座標。

今後は、基礎地形マスクを崩さない範囲で必要な支流・湿地・細水路を追加する。

# 街道設計時の確認画像ルール【確定】

街道アンカーを調整する際の確認用画像は、原則として**地形マスク版PNG**を使用する。

- 地形区分が分かる確認図を背景にする。
- ワールド座標のグリッドを重ねる。
- 基本グリッドは `500px` 間隔、`1000px` ごとに強調表示する。
- アンカーポイント番号を表示する。
- 必要に応じて町名、橋候補、水域交差地点を表示する。

# 移動バランス

- 中央部は比較的自由に歩ける。
- 西〜南西へ行くと湖沼と主河川によってルート選択が増える。
- リュメイ周辺では湖沼・ミオ湿原が大きなランドマーク兼障害物になる。
- ポルトナ西側には河口があり、港湾地形や街道設計に影響する。
- 北へ行くとカンデル山脈の横断点を意識する必要がある。

# 現時点で確定するもの

- 川・湖・湖沼は徒歩横断不可。
- 山岳の急斜面・稜線は徒歩横断不可。
- 内陸水域全体の固有地理名は**ナーヴァ水系**。
- 水系の大形状は確定基礎地形マスクを正とする。
- 主河川は北部寄りから南西湖沼水系へつながり、ポルトナ西側から南岸の海へ流れ込む。
- 旧3河川構成と旧橋座標は廃止し、基礎マスクに合わせて再設計する。
- 橋は通常橋1種類、固定配置、常時通行可、川地形IDを維持し通行のみ上書きする。
- 橋上でも通常エンカウントを行う。
- 橋の通行可能幅96px、見た目の幅100〜110px前後を基準とする。
- 主要橋はオルメド↔エルド、リュメイ↔レグナ、リュメイ↔ポルトナの3本で、位置・向き・長さまで確定済み。
- 橋名称・材質・外観は未確定。
- 主島の主要街道10本の基準アンカーと役割を確定済み。
- M-01、M-02、M-03の具体アンカーを確定済み。
- ブリガン島の町スカルドから主島北部・カンデル山脈へつながる隠れたルートの存在。
- 街道は中央縦断・西部・東部の複数系統を持つ網状交通とし、レグナへ全交通を集中させない。
- 都市基準座標を全街道の一点交差地点にはせず、都市ごとの方向別入口を利用する。
- J-01ポルトナ北分岐 `(8500,7550)` とJ-02カンデル西側合流 `(7600,2200)` の役割。
- 街道のA〜Dの格、基準幅、基本的な路面・地域差。
- 街道設計用の確認画像は原則、地形マスク版PNG＋500pxグリッド（1000px強調）を使用する。
