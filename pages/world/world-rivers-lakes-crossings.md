# 主島の川・湖・橋・山岳横断

主島の確定ワールド座標、7エリア、主要街道を前提にした移動障害の配置。

目的は、**どこへ行くにも迷路になるほど複雑にはせず、かといって町同士を直線で歩くだけにもならない**移動構造を作ること。

## 基本ルール【確定】

- 川は徒歩では渡れない。
- 湖は徒歩では入れない・横断できない。
- 山岳の急斜面・稜線は徒歩では越えられない。
- 峠周辺も自由横断はできず、**整備された峠道・岩門・洞道など、明示された横断ルートだけを通れる**。
- 川を渡れるのは橋などの明示された横断地点だけ。
- 水泳で強引にショートカットする移動は採用しない。
- 主要街道を使えば主島8町すべてへ到達できる。
- ただし、橋・湖・山稜によって街道は適度に曲がり、探索路には迂回や選択肢が生まれる。
- 一本道化を防ぐため、重要区間には原則として「主要ルート1本＋遠回りできる補助ルート1本」を用意する。ただし全区間を二重化はしない。

---

# 水系

## 1. 西中央川

北部山岳南西斜面から西部森林と中央草原の境界を流れ、南西湖沼へ注ぐ主河川。

### 基準ライン

```text
WEST_CENTRAL_RIVER = [
  (6900, 2750),
  (6750, 3150),
  (7000, 3500),
  (6850, 4000),
  (6600, 4450),
  (6500, 4900),
  (6250, 5300),
  (6100, 5600)
]
```

### 役割

- 西の森の町とエルドを完全に分断する壁にはしない。
- 西街道は橋を1回渡ることで自然に曲がる。
- 下流へ行くほど湿地化し、湖沼エリアの景観へつながる。

---

## 2. 東高原川

北東高原から東部荒野へ流れ、南東海岸へ抜ける河川。

### 基準ライン

```text
EAST_HIGHLAND_RIVER = [
  (10100, 2850),
  (10350, 3350),
  (10150, 3850),
  (10400, 4300),
  (10650, 4750),
  (10550, 5200),
  (10900, 5650),
  (11300, 6100),
  (11700, 6550)
]
```

### 役割

- 高原の町から東の町へ向かう道を少し蛇行させる。
- 中央都市から東の町へ向かう交易路にも横断点を作る。
- 東部は崖と川を組み合わせ、見通しは良いのに真っ直ぐ進めない地形にする。

---

## 3. 南流川

南西湖沼の水を受け、中央南部を通って南岸へ流れる川。

### 基準ライン

```text
SOUTH_RIVER = [
  (6500, 6200),
  (6850, 6450),
  (7200, 6700),
  (7550, 6900),
  (7900, 7200),
  (8150, 7550),
  (8100, 7900)
]
```

### 役割

- 湖沼の町から港へ向かう南西街道に1回の橋渡りを要求する。
- 中央都市から港への幹線は川の東側を基本にし、必要以上に橋だらけにしない。
- 港直前で川が迷路状に分岐する構造にはしない。

---

# 湖

## 翠の湖【主湖】

南西湖沼地帯の中心となる大きな湖。仮称。

### 基準外形

```text
EMERALD_LAKE = [
  (5200, 5350),
  (5550, 5150),
  (6000, 5200),
  (6350, 5450),
  (6450, 5800),
  (6250, 6050),
  (5900, 6150),
  (5500, 6050),
  (5200, 5750)
]
```

湖沼の町 `(6000,6100)` は湖の南岸〜南東岸に接する位置関係とする。

### 移動への影響

- 湖そのものは横断不可。
- 湖の北岸と南岸に道を分け、どちらから回るか選べる。
- 北岸は西の森・中央都市方面へ便利。
- 南岸は港方面へ便利。
- 湖の周囲を完全な一本道にはせず、湿地や小丘で短い探索枝を作る。

## 小湖群

主湖の西〜南西に小さな湖を2〜3個置くが、**主要街道を何度も分断する配置にはしない**。

目安中心座標：

- 小湖北：`(4700,5600)`
- 小湖南：`(5000,6400)`
- 小湖東：`(6700,5750)`

小湖群は探索・カード条件・景観用途を主とし、交通障害としては主湖より弱くする。

# 橋【確定基準位置】

主島の主要橋は、まず **6本** を基準とする。橋を増やしすぎて川の意味を消さない。

| ID | 仮称 | 座標 | 接続・役割 |
|---|---|---:|---|
| BR-01 | 森街道橋 | `(6,850,4,000)` | 西の森の町 ↔ エルド。西街道の主要橋 |
| BR-02 | 湖北橋 | `(6,300,5,350)` | 湖北側から中央草原へ抜ける補助ルート |
| BR-03 | 湖東橋 | `(6,850,6,450)` | 湖沼の町 ↔ 中央都市方面の主要横断点 |
| BR-04 | 南街道橋 | `(7,550,6,900)` | 湖沼の町 ↔ 南の港町。南西街道の主要橋 |
| BR-05 | 高原橋 | `(10,500,4,550)` | 高原の町 ↔ 東の町。高原街道・東街道系 |
| BR-06 | 東交易橋 | `(10,650,5,450)` | 中央都市 ↔ 東の町。南東街道の主要橋 |

### 橋配置の考え方

- 1本の川に等間隔で橋を並べない。
- 主要街道上の橋は分かりやすく、探索路の橋は少し外れた位置にする。
- 橋を見つければ進める、という読みやすい地形にする。
- 橋を1本見逃しただけで数千px戻らされる構造は避ける。
- BR-02は必須街道ではなく、湖の北側を使う探索ショートカット寄り。

# 北部山岳と横断ルート

北部山岳は、山そのものをどこでも歩ける地形にはしない。

## 山岳障壁

おおよその障壁帯：

```text
x = 6200〜10000
y = 1200〜3200
```

この中に雪山、急斜面、崖、稜線を配置する。通常徒歩で横切れるのは、下記の整備ルートだけ。

## M-01 中央峠道

基準点：`(8,000,3,000)`

- 北の町 ↔ エルドを結ぶ主ルート。
- 最も分かりやすく、安全性も比較的高い。
- 中央縦断街道の一部。
- 峠の斜面そのものを登ってショートカットすることはできない。

## M-02 西岩門

基準点：`(6,450,2,950)`

- 西部大森林から北部山岳へ抜ける補助ルート。
- 狭い岩壁の切れ目・天然の門を通る。
- 西の森から北の町へ向かう遠回りルートとして機能。
- 主要街道ではないため、探索で見つける価値を持たせる。

## M-03 東峠道

基準点：`(9,650,3,000)`

- 高原側から北部山岳へ入る補助ルート。
- 高原の町と北の町の間に別経路を与える。
- 中央峠より険しく、寒冷・疲労の負荷を少し高められる。

### 山岳横断のルール

- 峠道以外の稜線・急斜面は徒歩不可。
- 一本道の長い山道にはせず、途中に見晴台・洞窟・脇道を置ける余白を残す。
- 北の町へは中央峠道が最短。西岩門・東峠道は遠回りだが探索価値がある。
- 山岳横断点を増やしすぎず、「山が地形障害である」感覚を保つ。

# 移動バランス

この配置では、主島の移動は次の感触を狙う。

- 中央草原は比較的自由に歩ける。
- 西へ行くと川と森林で少しルート選択が増える。
- 南西へ行くと湖が大きなランドマーク兼障害物になる。
- 東へ行くと川と崖によって直線移動が崩れる。
- 北へ行くと山岳横断点を意識する必要がある。
- 南の港へは比較的分かりやすく到達できる。

つまり、**中央は自由、外周へ行くほど地形による誘導が少し強くなる**構造とする。

## 複雑化を防ぐ制限

- 主島全体で主要河川は3本を基本とする。
- 大型湖は1つ。
- 主要橋は6本を基本とする。
- 北部山岳の主要横断ルートは3本。
- 一つの町へ行くために連続で3本以上の橋を渡る構造は作らない。
- 主要街道上で、橋を探すためだけの長い往復を要求しない。
- 一本道の迷路ではなく、遠くから橋・谷・峠道の存在を視認または推測できる地形にする。

# 現時点で確定するもの

- 川・湖は徒歩横断不可。
- 山岳の急斜面・稜線は徒歩横断不可。
- 峠周辺は自由横断不可で、指定された峠道等のみ通行可能。
- 西中央川・東高原川・南流川の3河川。
- 翠の湖を主島最大の湖とする。
- BR-01〜BR-06の6橋を主要橋の基準位置とする。
- M-01〜M-03の3つを北部山岳の基本横断ルートとする。

# 後から調整できるもの

- 川幅・湖岸線の細部。
- 橋の見た目、名称、材質。
- 小湖群の正確な外形。
- 峠道内のカーブ、洞窟、見晴台、探索枝。
- 雨や季節による水位変化をゲームプレイへ使うかどうか。
