# エルド 配置座標

エルド町マップの実装基準。建物の見た目・外装意匠は後から変更できるが、**マップ寸法、道路、広場、門、主要施設の占有サイズと基本位置はこのページを基準とする**。

## 基本仕様

- マップ全体：**2048 × 2048 px**
- タイル：**64 × 64 px**
- グリッド：**32 × 32**
- 座標原点：左上 `(0, 0)`
- タイル座標：左上を `(0,0)`、右下を `(31,31)`
- 1タイル = 64px
- 建物座標は、特記がない限り外周を含む占有矩形を示す。
- 建物入口の正面には最低1タイル分の歩行可能スペースを確保する。

## 城壁・門

城壁は町の中心部を囲む。町外れ施設を同一マップ内に置けるよう、マップ端との間に外周エリアを残す。

- 西壁：`x=4` タイル列（256〜319px）
- 東壁：`x=27` タイル列（1728〜1791px）
- 北壁：`y=4` タイル行（256〜319px）
- 南壁：`y=27` タイル行（1728〜1791px）
- 4門はいずれも2タイル幅。中央道路と直結する。

|---|---|---|---|
| 北門 | x=15〜16 / y=4 | x=960〜1087 / y=256〜319 | 北の山道 |
| 南門 | x=15〜16 / y=27 | x=960〜1087 / y=1728〜1791 | 南の街道 |
| 西門 | x=4 / y=15〜16 | x=256〜319 / y=960〜1087 | 森・丘方面 |
| 東門 | x=27 / y=15〜16 | x=1728〜1791 / y=960〜1087 | 廃塔・遺跡方面 |

## 主要道路

主要道路は2タイル幅（128px）を基本とする。

- 南北大通り：`x=15〜16`、北門から南門まで
- 東西大通り：`y=15〜16`、西門から東門まで
- 中央広場へ接続する部分は広場床として扱う。
- 支道は原則1〜2タイル幅。各施設の入口が主要道路または支道へ必ず接続する。

## 中央広場

- タイル範囲：`x=12〜19 / y=12〜19`
- ピクセル範囲：`x=768〜1279 / y=768〜1279`
- サイズ：**512 × 512 px（8 × 8タイル）**
- 南北・東西大通りが広場中央を貫通する。
- イベント、待ち合わせ、NPC滞在地点として使用する。

## 住宅・背景建物の扱い

NPC32人全員に個別住宅を作る必要はない。住宅区は「住民が生活している密度」を見せるため、以下の背景建物枠を設ける。

- 北側旧市街：3〜5棟追加可能
- 西側住宅区：3〜4棟追加可能
- 東側住宅区：2〜3棟追加可能
- 南側：旅人向け小屋・倉庫を2〜3棟追加可能

追加背景建物は主要道路・確定施設・1タイルの最低歩行余白を侵食しない範囲で置く。外観サイズは原則2×2〜4×3タイルとする。

## 配置上の安全条件

- 確定施設同士の占有矩形は重複しない。
- 南北大通り `x=15〜16` と東西大通り `y=15〜16` は、中央広場以外でも建物で塞がない。
- 4門から中央広場まで、最低2タイル幅の連続歩行経路を維持する。
- 各主要施設入口前に最低1タイルの歩行可能領域を確保する。
- 図書館・カードの館・宿屋・食堂など別マップへ遷移する施設は、外観サイズと内部マップサイズを独立させる。
- NPC巡回ルートは原則として道路・広場・施設前スペースに置き、建物 footprint 内へ直接ルートを通さない。
