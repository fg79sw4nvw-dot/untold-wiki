## 名称変更履歴

- ネメリア → オルメド
- アウロス → ハルクァ
- ヴェルノク → レグナ
- ネレム → リュメイ
- マレスタ → ポルトナ
- サヴェリア → ボナペ

旧名は履歴参照用とし、現行の設計・実装・回答では新名称を使用する。

## 座標の扱い【確定】

- 町の地理上の配置と上記実装用基準座標は確定済み。
- レグナの旧基準 `(8,500,5,500)` は使用しない。
- ポルトナの旧基準 `(8,600,7,700)` は使用しない。
- スカルドの旧基準 `(5,000,1,700)` は使用しない。
- ポルトナ `(8,500,7,750)` とスカルド `(3,400,1,350)` は、承認済み町配置を確定基礎地形マスクへ正規化して確定した座標とする。
- 地形上の配置基準は `pages/world/terrain-allocation-final.md` を参照する。

## 主島名【確定】

主島そのものには正式な固有名を設定しない。開発上は「主島」と呼ぶ。

## 会話可能NPCの都市別粗配分【確定】

10都市に配置する常設・会話可能NPCは、以下を基準とする。

| 都市 | 人数 |
|---|---:|
| カルドラント | 24 |
| オルメド | 22 |
| エルド | 32 |
| ハルクァ | 20 |
| レグナ | 40 |
| リュメイ | 24 |
| モルグレイ | 26 |
| ポルトナ | 28 |
| スカルド | 24 |
| ボナペ | 22 |
| **合計** | **262** |

- 背景の通行人、群衆、イベント時だけ一時出現するNPCはこの人数に含めない。
- エルド32人は既存確定仕様を維持する。
- レグナはオルバ最大都市かつ交通・情報の中心として最多とする。
- ポルトナは港湾・物流による流動人口を感じられる配分とし、その他の町も都市規模と地域役割に応じて差をつける。
- 人物カード対象NPCはこの会話可能NPCの中に含める。
- 真相に関係する情報は少数の「真相を知るNPC」へ集中させず、各NPCが生活圏・職業・経験から得た断片だけを持つ構造を基本とする。
- 具体的なNPC個人、職業内訳、真相ネットワークとの接続、移動ルートは別途設計する。
