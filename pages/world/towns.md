## 座標の扱い【確定】

- 町の地理上の配置と上記実装用基準座標は確定済み。
- レグナの旧基準 `(8,500,5,500)` は使用しない。
- ポルトナの旧基準 `(8,600,7,700)` は使用しない。
- スカルドの旧基準 `(5,000,1,700)` は使用しない。
- ポルトナ `(8,500,7,750)` とスカルド `(3,400,1,350)` は、承認済み町配置を確定基礎地形マスクへ正規化して確定した座標とする。
- 地形上の配置基準は `pages/world/terrain-allocation-final.md` を参照する。

## 主島名【確定】

主島そのものには正式な固有名を設定しない。開発上は「主島」と呼ぶ。

## 都市規模・人口帯【D2確定】

人口は世界設定上の**常住人口の目安帯**として扱い、一人単位の厳密な国勢調査値は固定しない。

| 都市 | 規模区分 | 常住人口の目安 | 補足 |
|---|---|---:|---|
| レグナ | 大都市 | **10,000〜15,000人** | オルバ最大都市。交通・商業・情報の中心 |
| ポルトナ | 中大都市 | **6,000〜9,000人** | 港湾・物流都市。常住人口以上に流動人口が多い |
| モルグレイ | 中都市 | **4,000〜6,000人** | ガレド荒野の生活・修理・再利用の中心 |
| エルド | 中都市 | **3,500〜5,000人** | 中央草原北側の生活・交易拠点。開始地点として会話密度は高め |
| ボナペ | 中都市 | **3,000〜5,000人** | 漁業・市場・食文化で周辺から人が集まる |
| カルドラント | 中小都市 | **3,000〜4,500人** | 山岳産業・職人活動を中心にまとまる |
| リュメイ | 中小都市 | **2,500〜4,000人** | 湖沼・水路に沿って分散気味に居住する |
| オルメド | 中小都市 | **2,500〜3,500人** | 森林資源と共同体生活を軸にする |
| スカルド | 中小都市 | **2,000〜3,500人** | 島内共同体として独立性が高い |
| ハルクァ | 小都市 | **1,500〜2,500人** | 牧畜・季節利用地を含むため市街人口は少なめ |

### 人口帯の扱い【確定】

- 上記は設定上の人口規模を合わせるための基準であり、ゲーム画面へ全住民を表示する意味ではない。
- 会話可能NPC数と人口は比例させない。会話可能NPC数はゲーム上の情報密度・役割も含めて決める。
- 背景NPC、通行人、群衆表現によって都市規模を補う。
- ポルトナの船員・荷役・旅人、ボナペの季節漁業関係者など、一時滞在者は常住人口帯へ含めない。
- ハルクァでは町外の放牧地・季節滞在地点にいる住民も存在するため、市街の見た目は人口帯より小さく感じてよい。
- リュメイは湖沼・水路沿いに居住域が分散するため、密集市街だけで人口感を表現しない。
- レグナだけを現代的な巨大都市規模にせず、オルバ全体の人口密度は低〜中程度の世界として扱う。

### 実装上の規模感【確定】

- **大都市**：複数地区を明確に分け、中心部だけでは町全体を把握できない。
- **中大都市**：複数の機能地区を持ち、人・物の出入りの多さを強く見せる。
- **中都市**：徒歩探索で全体像を掴めるが、用途の異なる複数地区を持つ。
- **中小都市**：一つの中心部と周辺生活域・産業域の関係が読みやすい。
- **小都市**：主要施設が比較的まとまり、周辺の自然・産業空間と一体で町らしさを作る。

人口帯からマップ面積を機械的に算出せず、地形・産業・都市構造を優先して個別レイアウトを決める。

## 都市設計共通ルール【確定】

- 各町には最低1つ、その町固有の施設を用意する。
- 固有施設は単なる景観上の差別化ではなく、その町の地理・産業・歴史・物語上の役割から自然に生まれるものとする。
- 固有施設は、探索・情報・カード・イベント等のゲーム体験へ接続できるものを基本とする。
- 各都市の具体的な固有施設は、それぞれの専用ページを正本とする。

## 都市別行政【確定】

各都市の統治を同一の町長制へ統一せず、その土地で日常的に調整が必要な資源・産業・生活条件から自然に異なる形を持たせる。

| 都市 | 統治の基準方向 |
|---|---|
| エルド | 町長型 |
| カルドラント | 職人・産業評議型 |
| オルメド | 共同体合議型 |
| ハルクァ | 牧畜・季節調整型 |
| レグナ | 城主統治型 |
| リュメイ | 水路共同管理型 |
| モルグレイ | 分散自治型 |
| ポルトナ | 港務中心型 |
| スカルド | 共同体集会型 |
| ボナペ | 漁業・市場評議型 |

- 各都市とも自治を基本とする。
- 都市を越える案件では、それぞれの都市の代表者が協議へ参加する。
- 各都市の具体的な権限、選出、合議方式等は専用ページを正本とする。

## 会話可能NPCの都市別粗配分【確定】

10都市に配置する常設・会話可能NPCは、以下を基準とする。

| 都市 | 人数 |
|---|---:|
| カルドラント | 24 |
| オルメド | 22 |
| エルド | 32 |
| ハルクァ | 20 |
| レグナ | 40 |
| リュメイ | 24 |
| モルグレイ | 26 |
| ポルトナ | 28 |
| スカルド | 24 |
| ボナペ | 22 |
| **合計** | **262** |

- 背景の通行人、群衆、イベント時だけ一時出現するNPCはこの人数に含めない。
- エルド32人は既存確定仕様を維持する。
- レグナはオルバ最大都市かつ交通・情報の中心として最多とする。
- ポルトナは港湾・物流による流動人口を感じられる配分とし、その他の町も都市規模と地域役割に応じて差をつける。
- 人物カード対象NPCはこの会話可能NPCの中に含める。
- 真相に関係する情報は少数の「真相を知るNPC」へ集中させず、各NPCが生活圏・職業・経験から得た断片だけを持つ構造を基本とする。
- 具体的なNPC個人、職業内訳、真相ネットワークとの接続、移動ルートは別途設計する。
