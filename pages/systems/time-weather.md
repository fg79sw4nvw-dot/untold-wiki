# 時間・季節・天候

**状態：D3確定**  
**D3更新日：2026-09-16**

地域への実適用・現行地名・基準気温・weatherRegion管理は `pages/systems/weather-runtime.md` を正本とする。本ページは時間、季節、天候種類、基準遷移表、気温補正、寒冷、天候条件カード救済を管理する。

## 時間・季節【確定】

- 24時間制。
- **現実1分 = ゲーム内2時間**。
- ゲーム内1日 = 24時間 = 現実12分。
- **1季節 = 3日** = 現実36分。
- 春 → 夏 → 秋 → 冬 → 春でループする。
- 会話中、BOOK / CARD / MAP等の時間停止UI中はゲーム内時間を停止する。
- 宿泊、船移動、時間変更スペルの処理は各正本に従う。

### 時間帯【確定】

- **朝：6:00〜8:59**
- **昼：9:00〜16:59**
- **夕：17:00〜19:59**
- **夜：20:00〜5:59**

気温、NPC会話、カード条件、営業時間等の共通時間帯として使用する。

### 季節条件の導入方針【確定】

- 序盤は季節限定イベント・カードを少なめにする。
- 中盤以降、季節変更スペルの入手に合わせて季節条件を増やせる。
- 長時間の季節待ちだけを要求せず、自然経過または季節変更スペルで到達できる構造を基本とする。

## 天候【確定】

### 天候種類

基本：
- 晴れ
- 曇り
- 雨

条件付き：
- 雪
- 吹雪
- 雷雨
- 嵐
- 砂嵐

条件付き天候は、その地域・季節等で成立可能な時だけ遷移候補へ入れる。

### 更新時刻

ゲーム内3時間ごと：

`0:00 / 3:00 / 6:00 / 9:00 / 12:00 / 15:00 / 18:00 / 21:00`

- 時間停止中は更新しない。
- 地域別現在天候とプロフィール統合は `weather-runtime.md` の `weatherRegionId / weatherProfileId` 方式を使用する。
- 3時間ごとの抽選は現在天候を起点とする遷移方式。
- 各行の確率合計は100%。

# 気温【D3確定】

`現在気温 = 地域基準気温 + 季節補正 + 時間帯補正 + 天候補正 + 個別地点補正`

- 地域基準気温・現行地域名は `weather-runtime.md` を正本とする。
- 内部・表示とも1℃単位。
- 通常の町内部は**18℃固定**。

| 天候 | 補正 |
|---|---:|

| 雨 | -1℃ |

- 雷雨、嵐、吹雪、砂嵐の気温補正が必要な地域は `weather-runtime.md` の地域／個別地点データで明示する。個別指定なしでは、雷雨・嵐は雨、吹雪は雪、砂嵐は晴れの気温補正を継承する。

- 春・昼・晴れ18℃。
- 冬・夜・曇り／雨でも10℃。
- 冬の雪では昼4℃、朝夕3℃、夜2℃。
- 中央草原・エルド周辺では寒冷は主に冬の雪対策として機能する。

# 寒冷蓄積値【確定】

寒冷蓄積値は0〜100。ゲーム内10分ごとに現在気温で更新する。

| 現在気温 | 10分ごとの変化 |
|---:|---:|
| -1℃以下 | +6 |
| 0〜4℃ | +4 |
| 5〜9℃ | +2 |
| 10〜14℃ | -2 |
| 15〜19℃ | -4 |
| 20℃以上 | -6 |

- 50以上で状態異常「寒冷」。
- 発症後も蓄積は最大100まで継続。
- 寒冷中に30以下まで下がると解除。
- 寒冷中は空腹度減少速度が通常の2倍。
- 空腹度の通常速度は `pages/systems/player-state.md` を正本とする。
- 防寒装備等の個別補正は各アイテム仕様に従う。

# 天候条件カードの救済【確定】

天候条件を完全な乱数待ちにしない。

- 必要INFOに対応する `clueId` が有効で、未取得カードの対象地域にいる等の個別条件成立中だけ、必要天候への遷移確率を内部補正できる。
- 対応RECORDを削除し `clueId` が無効になれば補正も解除する。

## 連続失敗補正

- 条件成立中、3時間更新で必要天候へ遷移しなければ1回外れとして数える。
- 外すたび次回確率を段階的に上げられる。
- 必要天候が発生した時点で連続失敗回数・追加補正をリセット。
- カード取得後はそのカード用補正を終了。
- 補正値・失敗回数はプレイヤーへ表示しない。

## No.03 雨を知らない石【確定】

- 対象：カナタ平原・エルド地方。
- 条件：カード未取得で、「場所」と「雨でも濡れない石」に対応する2つの `clueId` が有効、かつプレイヤーが対象地域にいる。
- 雨への基本補正：**+15ポイント**。
- 失敗1回につきさらに**+10ポイント**。
- 追加補正上限：**+30ポイント**。
- 最大補正：**+45ポイント**。
- 雨発生時、連続失敗と追加補正をリセットし、条件継続中は次回から基本+15へ戻る。
- カード取得で終了。
- 雨へ加算した分は他の現在候補天候から原則均等に減算し合計100%を維持する。
- 0%未満になる候補は0で止め、残り減算を他候補へ再配分する。

この共通確率再配分は `weather-runtime.md` の処理を使用する。
