# 時間・季節・天候

## 時間・季節

- 24時間制。昼夜の変化あり。
- 現実1分 = ゲーム内2時間。
- ゲーム内1日 = 24時間 = 現実12分。
- 1季節 = 3日 = 現実36分。
- 季節は春 → 夏 → 秋 → 冬 → 春の順でループする。
- 時間帯や季節がNPC会話やカード取得条件に影響する。
- 会話中は時間停止。
- BOOK / CARD / MAPなどのメニューを開いている間も時間停止。
- 宿泊時は任意の時間帯まで時間をスキップできる。

### 季節条件の導入方針

- 序盤は季節限定イベント・季節限定カードを少なめにする。
- 季節変更スペルがある程度集まる中盤以降から、季節条件を使うイベントやカードを増やす。
- 季節待ちを強制するのではなく、自然経過または季節変更スペルで条件を満たせる設計にする。

### 季節変更スペル使用時

- 指定した季節の **1日目** に移動する。
- 時刻は使用時の時刻を維持する。
- 例：春2日目 14:00 に夏変更スペルを使った場合、**夏1日目 14:00** になる。
- 季節変更後に、その季節のイベントを複数こなせる余裕を確保する意図がある。

## 天候

### 天候の種類

基本天候は以下の3種。

- 晴れ
- 曇り
- 雨

加えて、地域・季節・時間帯・イベント・所持している情報などの条件によって限定的に発生する天候として、以下を用意する。

- 雪
- 吹雪
- 雷雨
- 嵐
- 砂嵐

限定天候は常時の基本抽選に混ぜるのではなく、その天候が成立し得る条件を満たしている場合にのみ遷移候補へ加える。

### 天候更新タイミング

- 天候判定はゲーム内3時間ごとに行う。
- 基本的な更新時刻は 0:00 / 3:00 / 6:00 / 9:00 / 12:00 / 15:00 / 18:00 / 21:00 とする。
- 会話中やBOOK / CARD / MAPなどで時間が停止している間は天候更新も進まない。

### 地域別管理

- 天候は世界全体で1つを共有せず、地域ごとに別管理する。
- 各地域は現在の天候と、その地域専用の天候遷移テーブルを持つ。
- 地域ごとに気候差を表現できるよう、同じ現在天候でも次の天候への確率は地域ごとに変更可能とする。
- 雪・吹雪・砂嵐など、地域によって本来発生しない天候は候補から除外できる。

### 天候遷移方式

- 3時間ごとの抽選は完全な独立抽選ではなく、**現在の天候を基準に次の天候を決める遷移方式**とする。
- 各天候ごとに「次の3時間でどの天候へ変わるか」の確率を設定する。
- 現在と同じ天候が継続する確率も遷移テーブル内に含める。
- 遷移確率の合計は100%とする。
- 限定天候が条件を満たして遷移候補へ追加された場合は、その地域・条件に応じた専用の遷移確率を適用する。
- 具体的な遷移確率は地域ごとに決定する。

### 中央草原・エルド周辺：春・夏・秋【確定】

春・夏・秋は基本天候3種のみを対象とし、以下の遷移確率を使用する。

| 現在の天候 | 晴れへ | 曇りへ | 雨へ |
|---|---:|---:|---:|
| 晴れ | 60% | 30% | 10% |
| 曇り | 25% | 45% | 30% |
| 雨 | 20% | 40% | 40% |

- 晴天は比較的継続しやすい。
- 晴れから直接雨になる確率は低く、晴れ → 曇り → 雨の流れが起こりやすい。
- 雨は1回の更新で必ず終わるわけではなく、40%で継続する。

### 中央草原・エルド周辺：冬【確定】

冬のみ雪を通常の遷移候補に追加する。中央草原は雪国ではなく、雪は時々発生する程度とする。吹雪は通常発生しない。

| 現在の天候 | 晴れへ | 曇りへ | 雨へ | 雪へ |
|---|---:|---:|---:|---:|
| 晴れ | 55% | 30% | 10% | 5% |
| 曇り | 20% | 45% | 25% | 10% |
| 雨 | 15% | 40% | 35% | 10% |
| 雪 | 15% | 45% | 10% | 30% |

- 雪は晴れから直接発生することもあるが低確率。
- 曇り・雨から雪へ遷移する方が起こりやすい。
- 雪は30%で継続し、45%で曇りへ戻るため、長時間降り続けるより一時的な降雪になりやすい。
- 季節補正以外の限定天候、カード・`clueId` による補正はこの地域の基準テーブルとは別に扱う。

## 気温【一部確定】

- 世界に**現在気温**の概念を導入する。
- 現在気温は、**地域の基準気温 + 季節補正 + 時間帯補正 + 天候補正**で算出する。
- 気温は内部では**1℃単位**で扱う。
- プレイヤーにも現在気温を「7℃」のように実数値で表示する。
- 地域ごとに基準気温と各補正を持たせる。

### 中央草原・エルド周辺の基準気温【確定】

- **春・昼・晴れを18℃**とする。
- 中央草原・エルド周辺では、冬の雪の日以外は寒冷蓄積値が増加しないように調整する。
- そのため、雪以外の条件では現在気温が最低でも10℃となるようにする。

季節補正は以下とする。

| 季節 | 補正 |
|---|---:|
| 春 | 0℃ |
| 夏 | +8℃ |
| 秋 | -2℃ |
| 冬 | -5℃ |

時間帯補正は以下とする。

| 時間帯 | 補正 |
|---|---:|
| 昼 | 0℃ |
| 朝・夕 | -1℃ |
| 夜 | -2℃ |

天候補正は以下とする。

| 天候 | 補正 |
|---|---:|
| 晴れ | 0℃ |
| 曇り | -1℃ |
| 雨 | -1℃ |
| 雪 | -9℃ |

- 冬・夜・曇りまたは雨でも `18 - 5 - 2 - 1 = 10℃` となり、寒冷蓄積値は増加しない。
- 冬の雪では、昼4℃、朝・夕3℃、夜2℃となり、寒冷蓄積値が増加する。
- この気温設計により、中央草原・エルド周辺では状態異常「寒冷」は原則として**冬の雪への対策要素**として機能する。
- 他地域では地域ごとの基準気温と補正を別途設定する。

寒冷との関係は以下を基準とする。

| 現在気温 | 寒冷への影響 |
|---:|---|
| 20℃以上 | 寒冷蓄積値が大きく減少する |
| 15〜19℃ | 寒冷蓄積値が中程度に減少する |
| 10〜14℃ | 寒冷蓄積値がゆっくり減少する |
| 5〜9℃ | 長時間滞在すると寒冷になる可能性がある |
| 0〜4℃ | 寒冷蓄積が進みやすい |
| -1℃以下 | 寒冷蓄積がかなり進みやすい |

### 寒冷蓄積値【確定】

- 寒冷状態は、気温が一定値を下回った瞬間に即時発生するのではなく、内部の**寒冷蓄積値**によって管理する。
- 寒冷蓄積値は **0〜100** の範囲で管理し、下限0・上限100とする。
- 寒冷蓄積値は**ゲーム内10分ごと**に現在気温に応じて更新する。
- 気温帯ごとの変化量は以下とする。

| 現在気温 | 10分ごとの寒冷蓄積値変化 |
|---:|---:|
| -1℃以下 | +6 |
| 0〜4℃ | +4 |
| 5〜9℃ | +2 |
| 10〜14℃ | -2 |
| 15〜19℃ | -4 |
| 20℃以上 | -6 |

- 寒冷蓄積値が **50以上** になった時点で状態異常「寒冷」が発生する。
- 寒冷状態になった後も寒冷蓄積値は保持され、寒い環境では最大100まで上昇し続ける。
- 寒冷状態中に寒冷蓄積値が **30以下** まで下がった時点で寒冷を解除する。
- 発症基準50と解除基準30を分けることで、境界付近で寒冷状態が短時間に発症・解除を繰り返さないようにする。
- 寒冷状態中は空腹度の減少速度が通常の2倍になる。
- 防寒装備、焚き火、宿泊、温泉などによる追加補正は別途設定できる。

## サバイバル

- HPと空腹度は最大100。
- 空腹度0でHPが減少する。
- 状態異常：毒／寒冷／負傷／疲労。
- 徒歩が基本。瞬間移動はスペルなど限定的な手段。
- 空腹0の時は回復効果を軽減する案がある。

## 天候条件カードの救済

天候条件を完全な乱数待ちにしない。

必要情報をブックに記録済みで、未取得カードの対象地域にいる場合、そのカードに必要な天候への遷移確率を内部的に上げることができる。

補正判定は記録文そのものではなく、対応する `clueId` が現在有効かどうかを基準にする。必要な記録を削除して `clueId` が無効になった場合は補正も解除される。

### 連続失敗時の補正【確定】

- 必要情報が揃い、対象地域にいるなど、そのカードの天候補正条件が成立している間のみ適用する。
- 3時間ごとの天候更新で必要天候へ遷移しなかった場合を「1回外した」と数える。
- 外すたびに、次回以降の必要天候への遷移確率を段階的に上げる。
- 必要天候が実際に発生した時点で、連続失敗回数と追加補正をリセットする。
- カード取得後は、そのカードのための天候補正自体を終了する。
- 補正の存在、連続失敗回数、上昇量はプレイヤーには表示しない。

### No.03 雨を知らない石：雨補正【確定】

- 対象：中央草原・エルド周辺。
- 条件：カード未取得で、「場所」と「雨でも濡れない石」の2つの必要情報に対応する `clueId` がともに有効であり、プレイヤーが中央草原・エルド周辺にいること。
- 条件成立中は、3時間ごとの天候遷移で**雨への確率に基本補正として +15ポイント**する。
- 条件成立中に雨を引けなかった場合、連続失敗1回につき**さらに +10ポイント**する。
- 連続失敗による追加補正の上限は**+30ポイント**とする。
- したがって、基本補正を含む最大補正量は通常の遷移確率に対して**+45ポイント**となる。
- 雨が実際に発生した時点で連続失敗回数と追加補正をリセットし、条件が継続している場合は次回以降ふたたび基本補正 +15ポイントから開始する。
- 「雨を知らない石」を取得した時点で、このカード専用の雨補正は終了する。
- 雨へ加算した確率ぶんは、**その時点で遷移候補になっている雨以外の天候から原則として均等に減算**し、合計100%を維持する。
- 均等減算で端数が出る場合は実装上の丸めで調整し、特定の天候へ意図的な偏りは持たせない。
- ある天候の確率が0%未満になる場合は0%で止め、残りの減算量を他の候補天候へ再配分する。

この救済は、条件を正しく揃えたプレイヤーが長時間ランダム待ちになることを避けるための内部補正として扱う。
