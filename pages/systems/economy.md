# 経済・価格

**状態：D3共通仕様確定**  
**D3更新日：2026-09-16**

## 基本

- 通貨名は **ジェニー**。
- 依頼を主要な収入源の一つとする。
- 探索・情報・アイテム獲得を主目的とし、通貨獲得だけがゲームの中心にならないようにする。
- 基準価格のものさしとして **パン10ジェニー** を維持する。
- ゲーム内金額はすべて**整数ジェニー**で扱い、小数ジェニーは存在しない。
- 個別の商品価格、料理価格、作業料金、情報料金、依頼報酬等の製品版データはD4で決める。D3では算出・利用・営業時間・在庫等の共通規則を確定する。

# 通常ショップ

## ショップ分類【確定】

通常ショップは以下の4種類を基本とする。

1. **食料店**
2. **装備店**
3. **パック店**
4. **雑貨店**

- 旧「スペル店」は **パック店** と呼ぶ。
- 食料店は原則として食料カテゴリを扱う。
- 装備店は原則として装備カテゴリを扱う。
- 雑貨店は店舗ごとに必要なカテゴリの商品を扱える。
- パック店はスペルカード単品を販売せず、パック購入時にその場で抽選してスペルカードを入手する。
- パックそのものをフリーポケットへ所持する方式にはしない。
- 情報屋、宿屋、食堂、作業場は通常ショップとは別のサービス施設として扱う。

## 購入・売却【確定】

- 通常ショップで購入した物品は、その場でカード化してフリーポケットへ収納する。
- パック店だけはパック自体をカード化せず、抽選されたスペルカードを直接収納する。
- 食料店・装備店・雑貨店では、売却可能な所持カードを売却できる。
- パック店は購入専用で、売却機能を持たない。
- 売却したカードはフリーポケットから失われる。
- 買い戻し機能は設けない。

### 購入価格

- 購入価格はカードごとに設定する。
- 同じカードは、販売店舗・町・地域が違っても同一価格とする。
- 店舗差は品ぞろえで表現し、同一商品の地域別価格差では表現しない。
- パックはカード単体ではなくパック種類ごとに価格を持つ。
- 価格は1ジェニー単位の整数とする。

### 売却価格

- 購入価格を持つ売却可能カードは、原則として **購入価格の20%** を売却価格とする。
- 計算結果に端数が出た場合は**小数点以下を切り捨てる**。
- 売却可能として設定されたカードで計算結果が0になる場合は、最低売却価格を **1ジェニー** とする。
- 購入できないが売却可能なカードは、カードごとに整数ジェニーの個別売却価格を設定する。
- 売却不可カードには価格を自動生成しない。

## 商品・在庫【確定】

- 具体的な品ぞろえは店舗ごとに個別設定する。
- ゲーム内全店舗で共通する固定商品セットは設けない。
- 通常商品は原則として**無限在庫**。
- 有限在庫にする場合は、その商品・店舗へ明示的に `stock` を設定した特殊商品だけとする。
- 有限在庫商品は、再入荷条件を明示した場合だけ再入荷する。再入荷条件がない場合、購入後に自動復活しない。
- 購入確定時に所持金、有限在庫、収納先カテゴリの空き容量を再確認する。
- 条件不足の場合は購入を成立させず、ジェニーも消費しない。

## 購入フロー【確定】

### 単品

`商品一覧 → 商品詳細 → 購入確認 → 確定`

- 商品詳細で名称、説明・効果、価格、必要な分類情報を確認できる。

### まとめ買い

- 食料店・装備店・雑貨店では複数種類の商品を同時選択できる。
- 同一商品の数量も指定できる。
- 共通の購入数量上限は設けず、所持ジェニー、有限在庫、フリーポケット容量を実質上限とする。
- 購入確認画面で商品・数量・合計金額を表示してから確定する。

### 割引

- 適用可能な割引券・クーポンを所持している場合、購入確認画面で使用する券を選べる。
- 割引は**対象商品の割引前小計へ1回適用**し、その結果に小数ジェニーが生じた場合は小数点以下を切り捨てる。
- 券の効果によって0ジェニーになること自体は禁止しない。
- 割引券は原則1回使用の使い切り型。
- 複数回使用、対象店舗・対象商品・割引率・併用可否等は券ごとの個別仕様とする。
- 常設セール等を採用する場合もD4の個別店舗・イベントデータとして扱い、共通価格を暗黙に変動させない。

## 売却フロー【確定】

- ショップ初期画面は購入側の商品一覧。
- 「売却」からフリーポケット表示へ切り替える。
- 売却不可カードは選択できない。
- 単品売却・まとめ売りの両方を可能とする。
- 売却確認画面で対象カードと合計売却額を確認後に確定する。
- 売却に購入用クーポンは適用しない。

# 営業時間・施設利用【D3確定】

## 共通原則

- **全ショップへ同じ営業時間を設定しない。**
- 時間制限のあるショップ・サービス施設は、D4の各施設データで `openTime` / `closeTime` を必須設定する。
- 24時間利用可能な施設は `alwaysOpen` として明示する。
- 営業開始時刻は利用可能、営業終了時刻ちょうどから利用不可とする。
- 日付をまたぐ営業時間も設定可能とする。例：18:00〜02:00。
- 営業時間の判定は**サービス利用可否**に対して行う。建物そのものへ入れるか、NPCへ通常会話できるかは施設・地域側の個別仕様と分離する。
- 閉店中でも建物へ入れる個別施設では、購入・売却・情報購入・調理依頼・製作依頼等の対象サービスだけを利用不可にできる。
- 営業中に開始したサービス画面を開いたままゲーム内時間が進行しない場合、途中で閉店扱いへ切り替えない。
- イベント等による臨時休業・臨時営業は個別状態で上書きできる。
- 曜日制の定休日を共通前提にはしない。必要な場合だけ個別イベント／カレンダー条件として設定する。

## 品ぞろえの共通ルール

- 具体的な商品・料理・情報・レシピ対象はD4で施設ごとに定義する。
- 地域らしさは価格差ではなく、**扱う対象・サービス・NPC・立地・文化**で主に表現する。
- ストーリー・依頼・季節等によって品ぞろえを変える場合は、商品側または施設側に解禁条件を持たせる。
- 条件未達の商品を「？？？」として陳列することを共通仕様にはしない。基本は一覧へ出さない。

# 雑貨店【確定】

- 取扱カテゴリに固定制限を設けない。
- 食料、装備、素材、その他等を店舗ごとに設定できる。
- 修理・鑑定・交換等の追加サービスは標準では持たない。
- 別系統施設の専用サービスを商品カテゴリだけを理由に自動付与しない。

# 食料店【確定】

- 原則として食料カテゴリを販売する。
- 購入品はフリーポケットへ入り、購入直後に店内で自動消費しない。
- 店内飲食・調理・特殊加工は標準機能に含めない。

# 装備店【確定】

- 原則として装備カテゴリを販売する。
- 購入品はいったんフリーポケットへ収納する。
- 購入完了直後に「装備する」を選択できる。
- 同じ装備枠に既存装備がある場合は変更確認後に入れ替え、外した装備はフリーポケットへ戻す。
- 装備カテゴリに空き枠がない場合は購入できない。
- 商品詳細で現在装備との自動比較は行わない。
- 修理・強化・加工・鑑定は標準機能に含めない。

# パック店【確定】

- 複数種類のパックを扱える。具体的な取扱パックは店舗ごとに設定する。
- パック名、価格、1パックの入手枚数、レア度別排出率を商品詳細に表示する。
- 排出される個別スペル一覧は表示しない。
- **1〜10パック**までまとめ買い可能。
- 1回のまとめ買いは同じ種類のパックだけを対象とする。
- 各パック・カード枠は独立抽選し、重複排出を認める。
- 購入確定前に全排出枚数分のスペルカテゴリ空き枠を要求し、不足時は購入不可。
- 1パック購入ではカードを順に見せる通常演出、2〜10パックでは短縮まとめ演出を使用する。
- 高レア排出時の専用演出は抽選率へ影響しない。
- 通常パックは原則無限在庫。販売期間を持つパックは個別設定できる。
- パック購入にも対象となる通常ショップ用割引券を使用できる。
- 売却機能は持たない。
- パックの排出率等の正本は `pages/systems/spells.md` とする。

# 宿屋【確定】

## 標準プラン

- **素泊まり：40ジェニー**
- **夕食付き：55ジェニー**
- **夕朝食付き：70ジェニー**

- 上記を標準基準とし、個別宿屋で±10〜20ジェニー程度の差を設定できる。
- 宿屋は原則**24時間入館・宿泊受付可能**。個別例外だけ上書きする。
- 受付NPCでは「宿泊する」「話す」を分ける。
- 宿泊フローは `プラン選択 → 宿泊時間指定 → 内容確認 → 支払い → 暗転 → 時間進行 → 回復 → 明転`。

## 宿泊時間

- 現在時刻から **4〜23時間後**まで自由指定。
- 4時間未満・23時間超は選択できない。
- 食事付きプランは開始時刻に関係なく選択可能。

## 回復

- 素泊まり：HPを100まで回復。空腹度は回復しない。
- 夕食付き：HPを100まで回復。空腹度+50、上限100。
- 夕朝食付き：HP・空腹度を100まで回復。
- 全プランで宿泊完了時に状態異常をすべて解除する。

## 時間処理

- 指定時間だけゲーム内時間を進める。
- 日付、時間帯、NPC状態、天候等は起床時刻まで進む。
- 宿泊中は空腹度を減少させず、起床時にプラン回復を適用する。
- 通常フィールドイベントを宿泊中に自動消化しない。個別に宿泊中発生が指定されたイベントだけ例外とする。
- 宿泊後は宿屋ごとの固定復帰ポイントへ戻す。
- 宿泊による自動セーブは行わない。

# 情報屋【確定】

- 通常ショップではなく、有料で情報を提供するサービス施設。
- 推理の正解そのものではなく、場所・時間・目撃・特徴等の材料を提供する。
- 事実として提示する情報へ意図的な嘘を混ぜない。噂・未確認情報はその確度を明示する。
- 情報プールは情報屋ごとに設定する。
- 最上位メニューは **「情報を買う」「聞き直す」「話す」**。
- 情報購入・聞き直しは通常会話A/B/Cを消費しない。

## 購入

- プレイヤーが情報の範囲・カテゴリ・テーマを選び、その範囲の**未取得情報から1件をランダム抽選**する。
- 同じ範囲では候補を一巡するまで重複しない。
- 候補0件なら購入不可で料金は発生しない。
- 残り件数は表示しない。
- 情報ごとにストーリー・依頼・地域・カード等の解禁条件を持てる。
- 取得履歴は全情報屋で共通管理する。
- 同一情報ID／情報グループを別情報屋から再購入できない。
- BOOKに同一情報ID／グループのRECORDが存在する場合も購入候補から除外する。
- 後からRECORDを削除しても購入候補へ戻さない。
- 情報料金は個別INFOではなく、選択する情報範囲ごとに設定する。
- `情報範囲選択 → 価格確認 → 支払い → 抽選 → 会話で提示` の順。
- 通常ショップ用クーポンは使用不可。
- 購入回数の共通上限は設けない。
- プレイヤーから情報を売る機能は設けない。

## 記録・聞き直し

- 購入情報はNPC発言として提示し、自動RECORDしない。
- 通常の記録UIから任意に記録できる。
- 購入情報は購入時刻から**6ゲーム時間**、同じ情報屋で無料で聞き直せる。
- 聞き直しても期限は延長しない。
- 聞き直しは営業時間内だけ利用でき、期限は閉店中も通常進行する。
- 購入・聞き直し会話は通常どおり「思い出す」の対象になる。

# 食堂【確定】

- 通常ショップではなく、食事提供と調理依頼を扱うサービス施設。
- 通常メニューは食堂ごとに個別設定する。
- 通常メニューは店側が材料を用意し、料理ごとの通常料金を支払う。
- 通常メニュー注文は1回1食分。

## レシピ調理

- 習得済み料理レシピは、必要素材をプレイヤーが用意し、素材＋調理料金で依頼する。
- 同じレシピを複数食まとめて依頼できる。
- 必要素材は1食分×数量。
- 調理料金は同一依頼内では数量倍せず、1回分だけ支払う。
- 通常メニュー料理もレシピ習得済みなら、通常料金ではなく素材＋調理料金を選べる。
- レシピ限定料理は通常メニュー販売せず、習得済みなら**どの食堂でも**調理依頼可能。
- 数量の共通上限は設けず、素材・所持金・完成品収納条件を実質上限とする。
- 最終確認時に料金・素材を消費する。
- 通常ショップ用クーポンは使用不可。

---

# 作業場【確定】

- 通常ショップではなく、習得済み製作レシピによる製作依頼を扱う。
- レシピ未習得で利用できる通常製作品は設けない。
- 製作料金は作業場ごとの固定額。
- 同じ作業場ではどの製作レシピでも1回の製作料金は同額。
- 1回の依頼では1種類の製作レシピだけを扱う。
- 同一レシピは複数個まとめて製作でき、必要素材は1個分×数量。
- 数量倍しても製作料金は1回分のみ。
- 共通数量上限は設けず、素材・所持金・完成品収納条件を実質上限とする。
- 最終確認時に料金・素材を消費する。
- 通常ショップ用クーポンは使用不可。

---

# D4で確定する経済データ

- 各通常商品の具体的な購入価格、個別売却価格、効果量。
- 各店舗の具体的な品ぞろえと営業時間。
- 有限在庫を使う特殊商品、数量、再入荷条件。
- 個別の割引券・食事券・施設専用割引。
- 各情報屋の情報範囲・料金・情報プール。
- 各食堂の通常メニュー価格・調理料金。
- 各作業場の固定製作料金。
- 依頼報酬等を含めた製品版全体の収支バランス。

D4で価格調整を行う場合も、本ページの共通算出ルール・売却率・端数処理・営業時間判定・在庫規則を暗黙に変更しない。
