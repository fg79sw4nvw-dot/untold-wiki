# 施設共通仕様

**状態：D3共通仕様確定**  
**D3更新日：2026-09-16**

このページは、同種施設へ共通適用する**利用機能・受付フロー・情報屋UI・サービス処理**の正本とする。

価格、売買、営業時間、宿泊料金、調理・製作料金等の経済仕様は `pages/systems/economy.md`、レシピ内容は `pages/systems/recipes.md` を優先する。各町の位置、外観、内部構造、担当NPC、固有イベント、個別の品ぞろえは各地域・D4コンテンツ側で管理する。

---

## 基本方針【確定】

- 共通仕様は、明示的な個別例外がない同種施設へ適用する。
- 地域差は共通ルールを複製せず、個別施設データで上書きする。
- 同じ機能を複数ページへ重複保存せず、価格・レシピ・地域配置等は各正本へ参照する。
- サービスUIを開いている間はゲーム内時間を停止する。
- サービス確定前に必要なジェニー・素材・空き枠等を再確認し、条件不足なら消費を発生させない。

---

# 宿屋【確定】

- 原則24時間、宿泊受付可能。
- 受付NPCへ話しかけた際は**「宿泊する」「話す」**を分け、通常会話を残す。
- 利用フローは `プラン選択 → 宿泊時間指定 → 内容確認 → 宿泊`。
- 最終確認で料金を支払い、`暗転 → 時間進行 → 回復処理 → 明転` の順で処理する。
- 客室を実際に操作可能にするか等は各宿屋の個別仕様とする。
- 標準プラン、料金、宿泊時間、回復、復帰位置等は `pages/systems/economy.md` を正本とする。

# 情報屋【D3確定】

## 基本役割

- 通常ショップではなく、**有料で推理材料となる情報を提供するサービス施設**。
- 正解そのものを販売せず、場所、時間帯、目撃、特徴等の材料を提供する。
- 事実として提示する情報へ意図的な嘘を混ぜない。
- 噂・未確認情報は、その確度が発言から分かる形にする。
- 情報プールは情報屋ごとにD4で定義する。

## 受付メニュー

最上位メニューは以下の3項目。

1. **情報を買う**
2. **聞き直す**
3. **話す**

- 「話す」は通常NPC会話として扱う。
- 情報購入・聞き直し会話は通常会話回数を消費しない。

## 「情報を買う」選択UI【D3確定】

- 「情報を買う」を選ぶと、その情報屋で現在利用可能な**情報カテゴリ一覧**を縦リストで表示する。
- 自由入力検索は設けない。
- 各カテゴリはD4データとして `categoryId / 表示名 / 料金 / 所属情報ID群 / 解放条件` を持つ。
- カテゴリ自体の解放条件を満たすまでは一覧へ表示しない。
- 解放済みカテゴリに現在購入可能な未取得情報が1件以上あれば選択可能にする。
- 解放済みだが未取得候補が0件の場合はカテゴリ名を残して選択不可とし、**「今は新しい話はない」**とだけ示す。
- 候補総数・残り件数は表示しない。
- カテゴリを選択すると、そのカテゴリの料金を確認して購入確定へ進む。

## 情報抽選・取得履歴

- 選択カテゴリに含まれる**現在解放済みかつ未取得の情報から1件をランダム抽選**する。
- 同一カテゴリでは候補を一巡するまで同じ情報を再抽選しない。
- 抽選候補0件なら購入不可で料金は発生しない。
- 各情報はストーリー、依頼、地域到達、カード取得等の個別解放条件を持てる。
- 購入済み情報の取得履歴は**全情報屋で共通管理**する。
- 別の情報屋に同じ情報IDがあっても、取得済みなら抽選候補から除外する。
- BOOK内に同一情報ID／同一情報グループの記録が存在する場合も購入候補から除外する。
- 一度取得済み・候補除外になった情報は、その後RECORDを削除しても購入候補へ戻さない。
- 単に聞いたことがあるだけで取得履歴・RECORDのどちらにも残っていない場合は、それだけで除外しない。

## 購入処理

`情報カテゴリ選択 → 料金確認 → 購入確定 → 支払い → 抽選 → 情報屋NPCが情報を話す`

- 所持ジェニー不足なら購入不可。
- 購入可能候補がある限り、共通の購入回数上限は設けない。
- 1件聞き終えると情報屋メニューを閉じる。続けて買う場合は再度NPCへ話しかける。
- 通常ショップ用クーポンは使用不可。
- プレイヤーから情報を売る機能は設けない。

## 情報の提示・RECORD

- 購入情報は情報屋NPCの発言として提示する。
- 自動RECORDしない。
- 情報の後、必要なら記録しておくようNPCの口調に合わせて自然に促せる。
- 購入直後・聞き直し時とも、通常NPC会話と同じ文選択型RECORD UIを利用できる。
- 情報購入・聞き直し会話も「思い出す」の対象とする。

## 「聞き直す」UI【D3確定】

- 購入した情報は**購入時刻から6ゲーム時間**、無料で聞き直せる。
- 期限は情報ごとに個別管理し、新しい購入や聞き直しで延長しない。
- 「聞き直す」を選ぶと、期限内の購入済み情報だけを**購入日時の新しい順**に縦リスト表示する。
- 一覧ラベルには、プレイヤーが実際に聞いた情報本文の**先頭1行を省略表示**して使う。新しい要約・見出しをゲーム側で生成しない。
- 検索・カテゴリ絞り込みは設けない。
- 項目を選ぶと、同じ情報をNPC会話として再提示する。
- 聞き直し終了後は施設メニューを閉じる。
- 6ゲーム時間を過ぎると専用聞き直しから消えるが、取得履歴は残る。
- 「思い出す」に残っている場合は、別途その共通ルールで参照できる。
- 聞き直し期限は営業時間外でも進む。
- 聞き直し自体は情報屋の営業時間内だけ利用可能。

# 食堂【確定】

## 基本役割

- 通常ショップではなく、**食事提供と調理依頼**を扱う。
- 通常メニューは食堂ごとにD4で定義する。

## 通常メニュー

- 店側が材料を用意し、プレイヤーは料理ごとの料金を支払う。
- 通常注文は1回につき1食。
- 1食は**「すぐ食べる」「持ち帰る」**を選択できる。
- 持ち帰る場合は食料カテゴリの空き枠が必要。

## 習得済み料理レシピの調理依頼

- プレイヤーが必要素材を用意し、調理料金を支払う。
- 1回の依頼では1種類の料理レシピだけを扱う。
- 同一レシピを複数食まとめて調理でき、共通数量上限は設けない。
- 必要素材は `1食分 × 指定数量`。
- 調理料金は数量倍せず、1回の依頼につき1回だけ支払う。
- 通常メニュー料理でもレシピ習得済みなら素材持込方式を選べる。
- レシピ限定料理は通常メニューには並べず、習得後の調理依頼だけで作る。
- レシピ限定料理は、習得済みなら原則どの食堂でも調理依頼できる。
- 複数食では**「すべて持ち帰る」「1つだけ食べる」**を選ぶ。
- 空き枠不足で持ち帰れない数量は確定できない。

## 支払い・割引

- 最終確認時にジェニーと素材を消費する。
- 所持金・素材不足なら確定不可。
- 通常ショップ用クーポンは使用不可。
- 食堂専用券等を作る場合は個別仕様とする。

---

# 作業場【確定】

- 通常ショップではなく、**習得済み製作レシピを使った製作依頼**を扱う。
- レシピ未習得でも買える「通常製作品」は標準機能として設けない。
- 習得済み製作レシピは、原則どの作業場でも依頼できる。
- 1回の依頼では1種類の製作レシピだけを扱う。
- 同一レシピを複数個まとめて製作でき、共通数量上限は設けない。
- 必要素材は `1個分 × 指定数量`。
- 製作料金は作業場ごとの1回分固定額とし、数量倍しない。
- 最終確認で素材・ジェニーを消費する。
- 所持金不足、素材不足、完成品カテゴリの空き枠不足なら確定不可。
- 通常ショップ用クーポンは使用不可。
- 修理・強化・鑑定等は作業場の標準機能に含めない。

---

## D4へ送るもの

- 各施設の具体的な営業時間・料金・品ぞろえ・情報カテゴリ・情報本文。
- 情報屋ごとのカテゴリ名、料金、所属情報、解放条件、NPC会話。
- 食堂の通常メニュー、個別料金、料理内容。
- 作業場の個別料金。
- 各施設の外観、内部レイアウト、担当NPC、固有イベント。

施設共通の利用フローと情報屋UIはD3確定仕様として扱う。
