# 物語基準・地域設計

このページは、UNTOLDで**地形・町・集落・ダンジョン・遺構・施設・NPC群・地域イベント**を新しく設計する際に参照する、物語側の横断正本とする。

目的は、場所を先に作って後から物語を貼り付けるのではなく、**現在の生活、過去の歴史、人物関係、情報、伏線、カード、プレイヤーの認識変化を一つの場所へ自然に重ねられるようにすること**にある。

このページは個別地域の具体仕様を上書きしない。地形、町、人物、カード等の個別事実は、それぞれの話題別正本を優先する。

## 参照関係【確定】

地域や場所を物語込みで設計する場合は、原則として以下を併用する。

- 世界の確定史・オルバと未開：`pages/world/world.md`
- 物語上の秘密・伏線：`pages/story/foreshadowing-ledger.md`
- 真相・情報・観察・推論の接続：`pages/story/information-architecture.md`
- 主人公：`pages/story/protagonist.md`
- ゲームマスター：`pages/story/gamemaster.md`
- 全体の設計思想：`pages/design-philosophy.md`

このページでは上記の長文を重複保存せず、**場所を設計するときに何をどう接続するか**を整理する。

# 物語の背骨【確定事項の設計用要約】

UNTOLDの地域設計では、以下の流れを物語全体の背骨として扱う。

1. **現在のオルバ**
   - 住民は文字を読めるが、本を長期記録として読む認識と、知識・出来事を体系的に残し継承する記録文化を失っている。
   - 図書館や本を保管する習慣だけが理由を失ったまま残っている。
   - 主人公は、この世界の「昔からそういうもの」で済まされている不自然さへ一般住民より強く引っかかる。

2. **UNTOLDとの接触**
   - 主人公はエルド図書館でUNTOLDを発見する。
   - UNTOLDは主人公を選定した特別な道具ではなく、ゲームマスターが記録文化を失った人間でも「読む・記録する」という認識へ入れるよう作った入口である。
   - 主人公は99枚の収集と、自分で気になった情報の記録を始める。

3. **探索・記録・照合**
   - プレイヤーは町、人物、生物、遺物、地形、遺構などを個別に探索する。
   - それぞれの場所だけでは意味が完結しない情報を、別地域のINFO・OBSERVATION・カード・口伝等と照合することで、オルバの歴史と現在の異常がつながっていく。

4. **約180年前の過去へ近づく**
   - 過去のオルバは未開へ到達し、記録によって航路・採取方法・知識を再現可能にした。
   - 接触は探索から交易、資源獲得、国家規模の大量採取へ拡大し、生態系被害や武力衝突へ発展した。
   - 未開側は再発防止のため、オルバから長期記録文化を失わせて隔離した。
   - この過去は、オルバだけを被害者、未開だけを加害者とする単純な構図にはしない。

5. **ゲームマスターという先行者**
   - ゲームマスターはオルバ出身で、主人公より先に記録概念を自力で再発見し、オルバの矛盾を追い、未開へ到達して過去の真相を知った。
   - 真相を一方的に公表したり、自分の答えを社会へ押し付けたりせず、UNTOLDと99枚の仕組みを残した。
   - 目的は「正解を教えること」ではなく、知った人間が自分で何を考え、何を選ぶかを見ることにある。

6. **99と0**
   - No.01〜99が正式な指定カードの収集範囲。
   - No.99はゲームマスター。
   - 主人公自身はその外側でNo.0として記録される。
   - No.0は99枚の続きではなく、それまで世界を観察し記録してきた側そのものを記録する位置づけとする。

地域設計では、すべての場所をこの背骨へ直接接続する必要はない。ただし、**メインストーリーへ接続する場所を作る場合は、この流れのどの段階を支える場所なのかを明確にする。**

# 場所に重ねる5つの物語レイヤー【設計基準】

地形・町・ダンジョンを設計するときは、必要な範囲で以下の5レイヤーを分けて考える。

## L1：現在の生活

その場所が、真相や伏線を知らない住民にとって**現在どういう場所なのか**。

- 何のために使われているか。
- 誰が暮らす・働く・通るか。
- 何が採れる、売られる、作られるか。
- 住民にとって危険・普通・特別のどれか。

物語上重要な場所でも、現在の生活上の意味を持たない「伏線展示場」にはしない。

## L2：地域の過去

その場所が現在の形になるまでに何があったか。

- 町の成立理由。
- 旧道・廃屋・遺構・地形利用の変化。
- 口伝や習慣として残ったもの。
- 約180年前以前・以後のどちらに由来するか。

メインストーリーと無関係な地域史を持たせてもよい。

## L3：世界の真相との接続

その場所が、記録文化封印・未開・ゲームマスター等の大きな真相へどの程度接続するか。

接続度は一律にしない。

- **直接証拠**：過去の出来事を強く示す遺構・物・記録可能情報。
- **二次的痕跡**：生物、菌類、植物、素材、言葉、習慣、口伝など、昔の往来の影響が薄く残ったもの。
- **無関係**：メインの過去とは直接関係せず、現在の生活・カード・地域独自の物語を担うもの。

すべての地域を直接証拠へつなげない。直接証拠がどこにでもあると、約180年間失われていた歴史として不自然になる。

## L4：人物関係と知識差

その場所にいる人物同士が、何を知り、誰を信じ、誰と利害・感情・過去を共有しているか。

- 人間関係そのもの。
- 同じ出来事に対する認識差。
- 情報の伝達経路。
- 知っているが隠す／一部だけ知る／誤解している等の差。

NPCの知識状態と開示姿勢は `pages/story/information-architecture.md` のモデルを使用する。

## L5：プレイヤーの認識段階

その場所を訪れた時点で、プレイヤーに何を感じてほしいか。

- 未認識
- 違和感
- 仮説形成
- 有力化
- 確定

同じ真相を示す場所でも、序盤の場所と終盤の場所では情報の強さを変える。

# 現時点で確定している地域別の物語機能

## エルド

**役割：現在のオルバの不自然さを日常として見せる開始地点。**

- 主人公の生活圏であり、UNTOLDを発見する図書館がある。
- 本の用途を誰も説明できないのに、図書館を維持し、本を大切に扱うという現在社会の矛盾を最初に体験させる。
- 主人公と一般住民の認識差を、説明ではなく日常会話・施設・行動から見せる場所として扱う。
- 主な接続：`HIDDEN-006`、`CLUE-002`、`NET-001`。
- エルド自体を約180年前の決定的事件の主要現場と自動的に設定しない。

## ポルトナ周辺

**役割：未開との物資往来を示す旧交易港・港湾遺構の中心。**

- 約180年前以前のオルバと未開の接触を示す、主要な直接痕跡の一つ。
- 交易、流通、外来素材、港湾構造等から過去へ近づける場所として使える。
- 現在のポルトナそのものが当時の港と完全に同一かどうかは未確定。
- 主な接続：`HIDDEN-004`。

## ブリガン島・スカルド周辺

**役割：未開へ向かう探索・採取隊の旧遠征拠点。**

- 探索が個人規模から組織化・大量採取へ変化していった痕跡を置ける主要地域。
- 主島北部・カンデル山脈へつながる隠れたルートの存在自体は確定している。
- ただし、その隠れたルートが旧遠征拠点と直接関係するかは未確定であり、勝手に接続しない。
- 主な接続：`HIDDEN-004`。

## セトラ島・セトラ廃都

**役割：関係悪化後の主要な旧衝突地域の一つ。**

- 交易や探索よりも、対立・被害・衝突側の歴史へ近づく主要地域として扱える。
- セトラ廃都が放棄された具体的原因は未確定。
- 主な接続：`HIDDEN-004`。

## その他の町・地形・島

- 現時点でメインストーリー上の具体的な役割が確定していない場所について、勝手に「実は旧遠征拠点だった」「未開との戦場だった」等の設定を追加しない。
- 約180年前の往来による**二次的影響**はオルバ各地へ薄く広がって残ることが確定しているため、生物、植物、素材、言葉、習慣、伝承等で間接的に接続できる。
- ただし二次的痕跡を置く場合も、何に由来する痕跡なのかを制作側で追跡できる状態にする。

# 人物関係の管理【確定】

地域設計では、NPCを一人ずつ独立した情報端末として置くのではなく、必要な人物について**関係そのものが情報の流れや解釈へ影響する構造**を持たせられるようにする。

人物関係には `REL-xxx` の管理IDを使用する。

## 関係データの基本項目

```text
REL-ID:
人物A:
人物B:
状態: 確定 / 暫定 / 未確定
表向きの関係:
実際の関係:
共有している過去:
AがBについて知っていること:
BがAについて知っていること:
感情・利害:
情報の伝達方向:
この関係が変化する条件:
物語上の役割:
関連HIDDEN / OPEN / CLUE / NET:
関連地域:
関連正本:
```

- 「実際の関係」が表向きと同じなら重ねて秘密を作らなくてよい。
- 家族、師弟、旧友、敵対、恋愛、因縁等を、ドラマを作るためだけに後付けしない。
- 関係を置く場合は、**人物の行動・知識・会話・依頼・地域の変化のどれかへ意味を持つこと**を基本とする。
- 秘密を含む関係は必要に応じて `HIDDEN` / `OPEN` / `CLUE` と接続する。
- 人物ごとの知識状態は `knows / partial / suspects / mistaken / unknown`、開示姿勢は `open / guarded / concealed` を使用する。

## 現時点で確定している重要関係

### REL-001：主人公 ↔ ゲームマスター【確定】

- 表向き：主人公はUNTOLDに残されたメッセージを通じて、正体不明の送り手の存在を知る。
- 構造上：ゲームマスターは主人公より前にオルバの矛盾を追い、記録概念を再発見し、未開へ到達した**先行者**。主人公は、その仕掛けを通じて同じ世界を別の経路で追う**後続の探索者**。
- ゲームマスターは主人公へ答えを与える教師ではなく、自分で観察・記録・判断させるための仕組みを残した人物。
- 主人公が特別に選ばれていた設定にはしない。
- 主な接続：`HIDDEN-002`、`HIDDEN-005`、`HIDDEN-007`、`CLUE-003`、`NONCLUE-001`。
- ゲームマスターが現在の主人公を直接監視している、事前に主人公個人を知っていた等は確定していないため追加しない。

### REL-002：主人公 ↔ オルバの一般住民【確定】

- 基本関係：同じ社会で生活しているが、**世界の不自然さへの認識に差がある**。
- 主人公は本や図書館の存在理由へ疑問を持つが、多くの一般住民は「昔からそういうもの」として受け入れている。
- ただし全NPCを同じ認識に固定しない。違和感を持つ者、秘密を一部知る者、意図的に隠す者を個別に設定できる。
- 主な接続：`HIDDEN-006`、`CLUE-002`、`NET-001`。

### REL-003：ゲームマスター ↔ オルバ【確定】

- ゲームマスターはオルバ出身。
- オルバ社会の内部から記録概念を自力で再構築し、世界の外側へ到達した。
- 真相を知った後も、社会全体へ答えや記録文化を一方的に戻すのではなく、UNTOLDという個人単位の仕組みを残した。
- この関係は、ゲームマスターがオルバを単純に救おうとする救世主でも、捨てた観察者でもないことを示す。

### REL-004：過去のオルバ側 ↔ 未開側【確定】

- 初期には探索・接触・交易が存在した。
- 記録による再現性によって接触が大規模化し、大量採取、生態系被害、武力衝突へ進んだ。
- 未開側は再発防止としてオルバの長期記録文化を封じた。
- どちらか片方だけを完全な善・悪に固定しない。
- 約180年前の具体的な人物・組織・国家・個人的関係は現時点では未確定。

# 伏線を場所へ置くときの基準【確定】

## 伏線は「場所の意味」と一体化させる

伏線を置くためだけのオブジェクトを増やすより、以下のように場所の本来の役割へ溶かす。

- 港の構造そのものが、現在の船では説明しにくい規模を持つ。
- 地域の素材・生物・植物の由来が、別地域の情報と照合すると不自然になる。
- NPC同士の認識差や口伝の食い違いが、同じ過去へ別方向から接続する。
- 現在は別用途で使われている建物が、後から過去の役割を再解釈できる。

上記は**設計方法の例**であり、個別地域の確定仕様ではない。

## 直接証拠と二次的痕跡を分ける

- ポルトナ周辺、ブリガン島・スカルド周辺、セトラ島・セトラ廃都は、主要な直接痕跡を置く地域として確定済み。
- その他の地域では、必要に応じて二次的痕跡を使う。
- 同じ真相を各地で同じ種類の証拠として反復せず、遺物、生物、地形、習慣、口伝、人物関係等へ分散する。

## 伏線IDとの接続

意図的な伏線は必ず `pages/story/foreshadowing-ledger.md` の `CLUE-xxx` として管理し、示唆対象を `HIDDEN-xxx` または `OPEN-xxx` へ接続する。

場所そのものが「意味深」に見えるが伏線ではない場合、後から勝手な意味付けが起こりそうなら `NONCLUE-xxx` を使用できる。

## 再解釈を優先する

長期的な伏線では、最初から答えを隠した暗号を置くことだけを考えず、後の情報で以前見たものの意味が変わる `recontextualizes` を積極的に利用する。

例：序盤ではただの生活習慣に見えたものが、過去を知った後には記録文化喪失の痕跡として見える、という構造。

# 地形を設計するときの物語チェック

地形を決めるときは、必要な範囲で以下を確認する。

1. **現在の利用**：住民・旅人・生物にどう使われているか。
2. **形成・過去**：自然地形なのか、人為的な変化があるのか。
3. **移動上の意味**：街道、孤立、交易、危険、迂回等へどう影響するか。
4. **生態系**：その地域固有の生物・植物・素材が何か。
5. **二次的痕跡**：未開との昔の往来による外来種・素材等を置くか。
6. **情報価値**：見ただけで得られるOBSERVATIONがあるか。
7. **後の再解釈**：別地域の情報を得た後に、この地形の意味が変わる余地があるか。

地形そのものへメインストーリー上の意味を必ず持たせる必要はない。

---

# 町・集落を設計するときの物語チェック

1. **成立理由**：なぜそこに町があるのか。
2. **現在の産業・生活**：住民は何で暮らしているか。
3. **地域間関係**：どこから物・人・噂が来て、どこへ出ていくか。
4. **共有認識**：住民が当然だと思っている地域常識は何か。
5. **口伝**：記録ではなく何が語り継がれているか。
6. **人物関係**：主要NPC同士の関係が情報や依頼へどう影響するか。
7. **知識差**：同じ事実について誰が何を知り、誤解し、隠しているか。
8. **カード・依頼**：地域固有の生活から自然に生まれる取得対象や問題があるか。
9. **メインストーリー接続**：直接証拠・二次的痕跡・無関係のどれか。
10. **認識段階**：訪問時にプレイヤーをどの段階まで進める場所か。

町の全住民をメインストーリー要員にしない。生活者として成立するNPC、地域固有の小さな問題、カードと無関係な会話も残し、世界が主人公のためだけに存在している印象を避ける。

---

# ダンジョン・遺構を設計するときの物語チェック

ダンジョンを作る場合、まず**なぜその場所が存在するのか**を決める。

最低限、以下を確認する。

1. 起源：自然形成／現在の施設／旧施設／遺構等のどれか。
2. 過去の用途：誰が、何のために使っていたか。
3. 現在の状態：なぜ放棄・維持・占拠されているか。
4. 現在の利用者・生物：誰がいるか、なぜいるか。
5. 地域との関係：近隣の町が存在を知っているか、どう認識しているか。
6. メインストーリーとの距離：直接証拠／二次的痕跡／地域独自／無関係。
7. 情報：どのINFO・OBSERVATION・QUESTIONを持つか。
8. 人物関係：関係するNPC、過去の利用者、依頼者がいるか。
9. カード：指定カードやフリーポケット対象とどう接続するか。
10. 再訪価値：後から情報・アイテム・時間帯等によって意味が変わるか。

すべてのダンジョンを約180年前の遺構にしない。自然洞窟、現在使われている施設、地域独自の廃構造、カード取得の探索場所などを混在させる。

# 地域設計の手順【確定】

1. まず、その場所が**現在の世界で何のために存在するか**を決める。
2. メインストーリーへ接続するなら、このページの物語の背骨のどこを担うか決める。
3. 約180年前との関係を、直接証拠・二次的痕跡・無関係・未確定から選ぶ。
4. その場所でプレイヤーに到達させたい認識段階を決める。
5. 必要なINFO・OBSERVATION・QUESTION・INFERENCEを組む。
6. 人物が関わる場合、RELと知識状態・開示姿勢を設定する。
7. 意図的な伏線を置く場合、CLUEとして示唆対象へ接続する。
8. カード・依頼・生態・施設等を、場所の現在の生活へ自然に接続する。
9. その場所だけで説明しすぎていないか確認する。
10. 個別正本へ具体仕様を記録し、必要なら情報ネットワーク・伏線台帳・人物関係を更新する。
