# 伏線・非公開設定台帳

このページは、UNTOLDの**セリフ、イベント、ストーリー、NPC反応、物や場所の演出**を設計する際に参照する、物語上の秘密・伏線・未確定事項の管理台帳とする。

通常の仕様書とは役割が異なる。ここでは「プレイヤーにまだ明かしていないが制作側では確定していること」と「制作側でも意図的にまだ決めていないこと」を分離し、さらに実際に置いた伏線が何を示唆しているのかを追跡する。

## 運用ルール【確定】

- セリフ、イベント、ストーリー、意味ありげなNPC反応、重要な物・場所の演出を新規設計する際は、`pages/design-philosophy.md` とあわせてこのページを参照する。
- **確定済み非公開設定**と**未確定設定**を混同しない。未確定の真相を、自然だからという理由で勝手に確定しない。
- 意図的な伏線には原則として管理IDを付け、**何を示唆する伏線なのか**を必ず紐づける。
- 回収先や示唆対象を説明できない「意味ありげな演出」は採用済み伏線として登録しない。
- 未確定設定を対象に伏線を置く場合、その伏線は現時点で残している解釈を不必要に潰さない表現に限定する。
- 非公開設定は、物語上の開示タイミングが来るまでNPCや主人公に不用意に言わせない。人物ごとの知識範囲が確定している場合は、その範囲を優先する。
- 未確定設定が確定した場合、関連する伏線をすべて見直し、矛盾するものがないか確認する。
- 伏線を回収した場合は削除せず、状態を**回収済み**へ変更して履歴を残す。
- 「非伏線」と明示された要素へ後から意味を付ける場合は、通常の補完ではなく**設定変更**として扱い、明示的に再検討する。

## 管理区分【確定】

### HIDDEN：確定済み非公開設定

制作側では事実として確定しているが、プレイヤーへはまだ明示していない、または開示方法を確定していない設定。

- `HIDDEN-xxx` のIDを使用する。
- 「事実そのもの」と「いつ・どう明かすか」は別々に管理する。
- 物語上まだ明かさないことは、設定が未確定であることを意味しない。

### OPEN：意図的な未確定設定

制作側でもまだ答えを固定していない設定、真相、開示方法、配置方針。

- `OPEN-xxx` のIDを使用する。
- 現行正本に明示的に未確定と書かれているものを優先して登録する。
- 候補が複数ある場合は候補を併記してよいが、候補を確定事項として扱わない。

### CLUE：採用済み伏線

実際の台詞、演出、物、場所、反応、名称などに、将来の意味や真相への示唆として意図的に持たせた要素。

- `CLUE-xxx` のIDを使用する。
- 必ず `HIDDEN-xxx` または `OPEN-xxx` などの示唆対象を紐づける。
- 状態は `採用済み` / `回収済み` / `廃止` を使用する。
- 実装済みかどうかはゲーム本体の実装状況と別管理とする。Wikiで採用済みでも、ゲーム本体にまだ実装されていない場合がある。

### NONCLUE：非伏線ガード

意味深に見えやすいが、現時点では伏線として扱わないと明示しておく要素。

- `NONCLUE-xxx` のIDを使用する。
- 将来のChatGPTや制作作業が、通常描写へ勝手に真相を付け足すことを防ぐために使用する。

# 伏線を追加するときの記録形式【確定】

新しい伏線を採用する場合、最低限以下を記録する。

```text
ID: CLUE-xxx
状態: 採用済み / 回収済み / 廃止
配置場所: イベント・NPC・カード・地名・物・記録など
実際の表現: 台詞や演出の要約
示唆対象: HIDDEN-xxx / OPEN-xxx
プレイヤーにその時点で推測してほしい範囲:
推測してほしくない範囲:
回収想定:
関連正本:
```

## セリフ設計時の確認項目【確定】

セリフに含み、濁し、話題転換、不自然な間、視線、言葉と行動の食い違いなどを入れる場合は、以下を確認する。

1. これは単なる人物表現か、伏線か。
2. 伏線なら、どのIDを示唆しているか。
3. その人物は、その事実を知っている設定なのか。
4. プレイヤーにこの時点でどこまで推測させたいのか。
5. 未確定設定に対して、未来の選択肢を必要以上に狭めていないか。
6. 後で回収できる具体的な接続先があるか。
7. `NONCLUE` として保護されている要素を勝手に伏線化していないか。

## 更新ルール【確定】

- 新しい非公開の確定事実が生まれたら `HIDDEN` に追加する。
- 物語上の重要事項を意図的に未確定のまま保持すると決めたら `OPEN` に追加する。
- 実際に伏線を採用した時点で `CLUE` に追加し、示唆対象を紐づける。
- 「これは意味を持たせない」と判断した重要な曖昧要素は `NONCLUE` に追加する。
- `OPEN` が確定した場合は、該当内容を個別の正本へ反映し、このページでは必要に応じて `HIDDEN` または公開済みの履歴へ移す。
- このページは物語上の秘密を管理するため、公開Wiki上で読める場合でも**プレイヤー向け攻略情報ではなく制作資料**として扱う。
