# 当面の開発マイルストーン

**状態：確定**  
**決定日：2026-09-14**  
**更新日：2026-09-15**

UNTOLDの当面の開発は、まず**エルドを「町として成立している状態」まで完成させ、その後に自由探索コアループを世界側へ広げる**順序で進める。

ここでいう「エルドの町完成」は、エルド内の全依頼・全カード・全イベントを消化することや、ゲーム内に地域単位の「クリア」状態を設けることを意味しない。あくまで**開発上の前段マイルストーン**であり、ゲーム内では導入後にプレイヤーが利用可能な導線から別地域へ向かえる自由探索方針を維持する。

## 第0マイルストーン：エルドの町完成

以下を満たした状態を、第0マイルストーンの達成条件とする。

1. **エルド町マップが町として一通り成立している**
   - 中央広場と東西南北の主要道路を自由に移動できる。
   - 現行正本で位置・役割が確定している主要施設、住宅区、市場、門、生活・生産地区が町マップ上で成立している。
   - 町内の通常移動・施設への出入り・マップ遷移が破綻しない。

2. **現時点で確定済みの主要施設が利用できる**
   - 個別仕様が確定している施設について、自由探索中に実際に出入り・利用できる状態にする。
   - 未確定の施設機能を、このマイルストーン達成のためだけに推測で補完しない。

3. **エルドのNPC32人が町の住民として成立している**
   - `ELD-NPC-001`〜`ELD-NPC-032` の役割・配置・活動時間・移動ルートを現行正本に従って扱える。
   - 各NPCに基本性格タイプを割り当て、既存のNPC会話ルールに従って通常会話の傾向を持たせる。
   - 自由探索中に出会えるNPCについて、主人公が原則発話しない前提でも通常会話が成立する。

4. **時間帯によって町の見え方が変化する**
   - NPCの活動時間・移動・非表示がゲーム内時刻に従って切り替わる。
   - 昼夜で人通りが変化し、深夜帯も既存仕様どおり少数のNPCが活動する。

5. **エルド内の基本的な自由探索が成立する**
   - プレイヤーが町内を自由に歩き、NPC・施設・調査対象へ任意の順序で接触できる。
   - 会話、調査、BOOK、記録、マップ等、エルド内で使用する基本操作が町の通常探索中に破綻しない。

6. **町完成と地域クリアを分離する**
   - エルド内の全依頼、全カード、全イベントの完了は第0マイルストーンの必須条件にしない。
   - エルドの町完成を、ゲーム内で他地域へ移動するためのクリア条件にはしない。
   - 個別の依頼・カード・施設機能は、それぞれの固有条件に従って進行する。

第0マイルストーンでは、**エルドを歩いたときに「導入用の背景」ではなく、NPCが生活し、時間が流れ、施設が存在する一つの町として成立していること**を重視する。

## 第1マイルストーン：自由探索コアループ完成

第0マイルストーン達成後、以下をすべて満たした状態を第1マイルストーンの達成条件とする。

1. **ゲーム開始導入が最後まで動作する**
   - 冒頭独立映像イベント
   - エルド図書館での開始イベント
   - BOOK入手
   - 初回カード化
   - 初回記録
   までを、実際のゲームプレイとして連続して進行できる。

2. **導入終了後、プレイヤーが自由に移動できる**
   - 特定の町や依頼を「クリア」することを、自由探索開始の必須条件にはしない。
   - プレイヤーは、現在移動可能な範囲の中から行動先を自分で選べる。

3. **複数地域を実際に行き来できる**
   - 最低限、エルドに加えて別地域1か所まで移動可能にする。
   - 第1マイルストーン時点で世界全域を完成させる必要はない。
   - 目的は、ゲーム構造がエルドだけに閉じていないことを実際のプレイで確認できる状態にすること。

4. **UNTOLDの基本ループを1周できる**

   **探索 → NPCとの会話・環境からの情報収集 → 必要な情報をBOOKへ記録 → 推理 → 条件達成 → カード化 → BOOKへの収集**

   この一連の流れを、実際のゲームプレイで最低1回成立させる。

5. **依頼を1件以上、開始から完了まで遊べる**
   - No.55「書喰い鼠」は、この条件を満たす依頼として使用できる。
   - ただし、書喰い鼠の完了を他地域へ移動するための必須条件とはしない。

6. **継続プレイに必要な基盤が動作する**
   - 日付・時間の進行
   - 1日目から2日目への遷移
   - セーブ／再開時の状態保持
   など、第1マイルストーンの範囲で継続プレイに必要な基盤を動作させる。

7. **iPhone実機で一連のプレイが破綻しない**
   - 移動
   - 会話
   - BOOK
   - 記録
   - カード化
   - マップ遷移
   - 必要なUI
   が、iPhoneを含む実機で一通り操作できる。

## 開発優先順位

今後の仕様決定・実装・検証は、原則として次の基準で優先する。

1. **まず第0マイルストーン「エルドの町完成」に必要な町マップ、施設、NPC、通常会話、時間帯挙動、町内探索を優先する。**
2. 第0マイルストーン達成後、第1マイルストーン達成に必要な他地域への導線、基本ループ、依頼、継続プレイ基盤へ進む。
3. エルドを開発上先に完成させても、ゲーム内でエルド全要素の完了を他地域移動の条件にはしない。
4. 自由探索を実証するため、第1マイルストーンではエルド以外の地域へ実際に移動できる導線と最低限の受け皿を用意する。
5. 99枚すべてのカード、全都市の詳細、全依頼など、当面のマイルストーン達成に不要な量産は後回しにできる。
6. 未確定仕様を実装都合で補完しない。必要な仕様が未確定の場合は、その項目を先に設計・確定する。

## エルドの位置づけ

- エルドは主人公の開始地点であり、序盤の主要な生活圏・導入舞台とする。
- BOOK入手、最初のカード化、最初の記録、序盤の依頼など、基本システムを自然に知る場として重要な役割を持つ。
- 開発順としては、まず町としてのエルドを一通り成立させる。
- ただし、エルドにはゲーム上の一律な「クリア」状態を設けることを前提としない。
- プレイヤーは導入後、エルドに留まって探索を続けても、利用可能な導線から別地域へ向かってもよい。
- 依頼やカード取得は、それぞれ固有の開始条件・進行条件を持たせ、地域単位のクリアフラグに一括依存させない。

## 今後のマイルストーン方針

第1マイルストーン以降も、原則として「特定地域をクリアしたか」ではなく、**ゲーム全体として成立した体験・機能の範囲**で定義する。

現時点の方向性は以下とする。

- **第0：エルドの町完成**
- **第1：自由探索コアループ完成**
- **第2：複数地域で探索・情報収集・カード取得が成立**
- **第3：世界全体の基本移動網と主要システム完成**

第2以降の具体的な達成条件は、必要になった段階で個別に確定する。
