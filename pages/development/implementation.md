# ChatGPT実装仕様・引き継ぎ

このページは、将来ChatGPTがこのWikiだけを読んでUNTOLDを実装できる状態にするための入口。

## 正本ルール

- 設定の正本は GitHub リポジトリ `fg79sw4nvw-dot/untold-wiki` の `main` ブランチ内のWiki本文。
- 会話上の記憶とWikiが食い違う場合、原則としてWikiの「確定」記述を優先する。
- `未定`、`案`、`一旦` を勝手に確定扱いしない。
- 実装時に不足する仕様は、推測で固定せず `未確定・保留事項` に追加する。
- 画像の基準はエルドの「基本ゲーム画面」。写実・写真調ではなく、温かい手描き2DファンタジーRPG調を優先する。

## ゲームの核

**探索 → 情報収集 → 記録する情報の選別 → 推理 → 条件達成 → カード化 → 収集**。

指定カード99種の収集がゲームの大きな目的。戦闘は最低限で、探索・情報収集・推理・発見の気持ちよさを主役にする。

## 実装時にWikiへ追加していく項目

### 各カード

## 現時点の共通カード化表現

- カード化前は原則として正式名称を表示しない。
- 遺物は条件が揃った対象地点を小さな光で示すことを基本とする。
- 生物は正体判明前には黒い影などの抽象表現を使える。
- 人物カード対象者は通常NPCと見た目で区別しない。
- カード化成立時は画面全体を暗転。
- カードが画面下からスライドインし、中央でNo.・名称・画像・説明文を表示する。
- 派手な魔法陣や過剰な粒子演出は原則使わない。


## 指定カードUI実装仕様【確定】

- 指定カード99種は共通の2:3縦長テンプレートを使用する。分類ごとにテンプレートは分けない。
- カード面に表示するのは番号・名称・イラスト・説明文のみ。
- 分類（遺物／生物／人物）は内部データとして保持するが、ゲーム内カード面には原則表示しない。
- 名称は必ず1行。長い場合は軽度の自動縮小を許容し、それでも収まらない名称は名称側を調整する。
- 説明文は最大4行。
- フォントは `Zen Old Mincho` を第一候補とし、`Noto Serif JP`, `serif` をフォールバックとする。
- カード内の具体的な余白・配置は、正式テンプレート画像 `assets/card-template-reference.jpg` を視覚基準とする。
- 未取得時はカード枠を描画せず、空の位置に番号だけを表示する。
- カード化演出とブック閲覧では同じカードコンポーネントを再利用する。
- 実装資産は「共通カードテンプレート＋カードデータ＋カード用イラスト素材」に分離する。完成カードの一枚絵をゲーム実装の正本にしない。
- カード用イラスト素材は必ず1:1の正方形で生成する。
- イラストの縁はぼかし、少し透過感を持たせて紙面へ馴染ませ、イラスト専用枠は付けない。
- 正式なカード視覚テンプレートは `assets/card-template-reference.jpg`。
- 取得場所、関連記録、関連NPC、関連イベント等はカード面ではなくブック側の別UIに表示する。

カードデータ例：

```json
{
  "id": 3,
  "name": "雨を知らない石",
  "category": "relic",
  "illustration": "assets/cards/003-rainless-stone.webp",
  "description": "雨の中でも、不思議と濡れることのない石。ありふれた姿をしているが、その表面にはどこか違和感がある。"
}
```

## データ実装の推奨方針

完成版では設定とゲームロジックを分離する。

- `cards`：カード定義
- `npcs`：NPC定義
- `locations`：マップ・施設
- `clues`：会話・観察から得る情報
- `records`：プレイヤーがブックへ記録した情報ID
- `quests`：依頼状態
- `flags`：イベント進行
- `inventory`：所持品
- `time` / `season` / `weather`：環境状態

カード化条件は可能な限りデータ駆動にし、個別カードのためだけのハードコードを減らす。

例：

```json
{
  "id": 3,
  "name": "雨を知らない石",
  "category": "relic",
  "requirements": {
    "records": ["rainless_stone_rumor", "rainless_stone_location"],
    "weather": "rain",
    "location": "TBD"
  }
}
```

## 完成判定

ChatGPTがこのWikiだけを読み、以下を追加質問なしで実装できる状態を目標にする。

1. 全マップと接続関係
2. 全99カードの取得フロー
3. 全NPCと会話・情報
4. メインストーリーの開始からエンディングまで
5. ブック・記録・カード・依頼・時間・季節・天候・経済・サバイバルの仕様
6. UIと基本ゲーム画面
7. アイテム・店舗・価格
8. セーブデータ構造
9. 音・演出の基準
10. 各イベントの発火条件と例外処理

不足している項目は `未確定・保留事項` に集約する。
