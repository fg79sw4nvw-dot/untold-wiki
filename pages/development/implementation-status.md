# ゲーム本体 実装状況

**更新日：2026-09-15**

このページは、`fg79sw4nvw-dot/untold-game` の `main` に現在反映されている実装内容と、Wiki上の確定仕様との差分を記録する。

実装内容そのものの仕様根拠は各正本ページを優先し、このページは**進捗確認専用**として扱う。

> **重要**
> `未実装`・`未接続`・`旧実装のまま` は、仕様上の `未確定` を意味しない。
> このページだけを根拠に「次に決める仕様」を判断しない。仕様状態を判断するときは、必ず話題ごとの個別正本と `pages/open-items.md` を確認する。

## 現在の実装方針

- ゲーム本体には、Wiki上で確定している内容のみを実装する。
- 未確定の台詞、座標、演出時間、開始値等を実装都合で補完しない。
- 第1マイルストーン「自由探索コアループ完成」に直接必要な導入・移動・記録・カード化・依頼・継続プレイ基盤を優先する。
- 旧「エルド通しプレイ完成」は現行マイルストーンとして使用しない。
