# ゲーム本体 実装状況

**更新日：2026-09-14**

このページは、`fg79sw4nvw-dot/untold-game` の `main` に現在反映されている実装内容と、Wiki上の確定仕様に対してどこまで接続済みかを記録する。

実装内容そのものの仕様根拠は各正本ページを優先し、このページは進捗確認用として扱う。

## 現在の実装方針

- ゲーム本体には、Wiki上で確定している内容のみを実装する。
- 未確定の台詞、座標、演出時間、強制移動ルート、開始値等は実装都合で補完しない。
- 第1マイルストーン「自由探索コアループ完成」に直接必要な導入・移動・記録・カード化・依頼・継続プレイ基盤を優先する。
- 旧「エルド通しプレイ完成」は現行マイルストーンとして使用しない。

## 今回反映した内容

### 正式なゲーム開始フローへの切り替え

- 従来の「開発用起点を選択してワールド移動を確認する画面」を正式なゲーム開始フローの入口としては使用しない構成へ変更した。
- 起動直後に、冒頭独立映像イベントを開始できるよう接続した。
- 冒頭では `pages/story/protagonist.md` の確定済み7文をそのまま使用する。
- 冒頭独立映像中は通常HUDを表示しない。
- 冒頭7文の自動進行には、現行Wikiにある暫定基準の「1文あたり約4秒」を使用する。
- 冒頭終了後は暗転を経て、エルド図書館導入フェーズへ移行する構造にした。

### エルド図書館導入

- 図書館を独立した屋内マップとして扱う既存実装を、現行Wikiの確定寸法へ更新した。
- 図書館1階は **9×7タイル、576×448px、1タイル64px** を実装基準とする。
- 入口は下辺中央、幅 **2タイル（128px）** とする。
- 図書館開始イベントを、通常フィールド上の自動進行イベントとして接続するための進行状態を追加した。
- 現時点では、棚間の具体的な強制移動ルートやBOOK取得位置など、未確定の座標は設定していない。

### BOOK初回閲覧

- BOOK初回閲覧用の専用表示を実装した。
- ゲームマスターの最初のメッセージは、通常会話HUDではなく開いた本の見開きとして表示する。
- メッセージ本文は `pages/story/gamemaster.md` の確定文をそのまま使用する。
- BOOKを読んだ直後の主人公の心の声 `（どういうことだ……？）` を実装データへ反映した。

### 司書への報告・BOOK持ち帰り

- BOOK初読後から司書への報告、BOOK確認、持ち帰り許可までの確定会話を実装データへ反映した。
- 司書の表向きの反応から「本当に読めない」「知っていて隠している」のどちらかを実装側で確定しない。
- BOOK持ち帰り許可後に、主人公がBOOKを所持している状態へ進められる構造にした。

### No.01「忘れられた栞」

- BOOK取得後、No.01未取得時だけ栞の小さな光を表示対象にする進行ロジックを実装済み。
- 光を調べた際にNo.01を取得し、既存のカード化表示へ接続できる構造を実装済み。
- `（栞が落ちてる。司書さんに渡しておくか。）` と `（……今の、何だ？）` を確定文として実装データ化した。
- No.01未取得のまま図書館を出ようとした場合は、退出を拒否して「なにか見落としている気がする」を返す。
- No.01取得後は、No.55導入会話が未発生なら図書館退出前にそちらを優先して開始する。

### 図書館内の開始直後インタラクション

- No.01取得前に司書へ再度話しかけた場合、`「気をつけて帰ってね。」` を返すロジックを追加した。
- 地下階段の扉を調べた場合、`（鍵がかかっている。）` を返すロジックを追加した。
- 地下扉の解禁条件・時期・理由は未確定のため実装していない。

### No.55「書喰い鼠」導入・依頼基盤

- No.01取得後、図書館退出時にNo.55導入会話を開始できるようにした。
- 導入会話は現行Wikiの以下4文へ修正済み。
  - 「あ、そうだ。ちょっとだけいい？」
  - 「最近、閉館したあとに、本棚が荒らされてることがあって。」
  - 「戸締まりはちゃんとしてるんだけど……誰がやってるのか分からないの。」
  - 「もし何か気づいたら、教えてくれる？」
- この時点では正式依頼を開始しない。
- 正式依頼は翌日以降にのみ開始できるよう進行条件を分離した。
- No.55の重要情報を、現行正本どおり以下3人へ割り当てた。
  - 司書（ELD-NPC-010）：棚の奥で小さな影を見た。人ではなく生き物のようだった。
  - 古物商（ELD-NPC-020）：昔、紙ばかりかじる小さな鼠を見たことがある。
  - 東区の青年（ELD-NPC-019）：甘い匂いのする木の実を置いておくと寄ってくる。
- 旧実装に残っていた「人がいなくなって静かになってから出てくる」という手がかりは削除した。
- 餌設置確認文 `「蜜漬け木の実を置きますか？」` を現行仕様として反映した。

### 初回記録チュートリアル

- No.55導入会話後に、初回記録チュートリアルへ移行できる進行ロジックを追加した。
- `（そういえば……あの本に、気になったことを書き留めておけるって書いてあったな。）`
- `（でも、どうやって……？）`
  の2文を確定文として反映した。
- 初回のみ「記録する」を表示・強調し、最初の記録完了までは他の通常操作を制限する状態を扱えるようにした。
- 1回記録が完了したら、通常操作へ戻せる構造にした。

## 現時点で未接続・未実装の部分

以下は、現行Wikiに具体値または確定文がないため、勝手に補完せず保留している。

- 図書館開始イベント冒頭の、司書が主人公へ感謝する**正確な台詞本文**。
- それに対する主人公の「好きでやっているだけ」という趣旨の**正確な発話本文**。
- 図書館開始イベント中の本棚間の**具体的な強制移動ルート**。
- BOOKを手に取る位置、手に取るまでの細かな間、固有演出の細かな秒数。
- 図書館自由操作で使用する家具・NPC・調査点の最終ピクセル座標。
- 帰宅イベント、自宅内部、1日目終了から翌朝開始までの実装。
- 翌朝の東区の青年とのBOOK確認イベントの最終台詞。
- No.55正式依頼を、実際のNPC会話・夜間調査・カード化・報告まで一本につないだ実プレイ。
- セーブ／再開とiPhone実機での通し確認。

## 現在の到達点

ゲーム本体は、個別ロジックだけの状態から、**起動 → 冒頭独立映像 → エルド図書館導入へ移行**する正式な開始フローへ接続し始めた段階にある。

BOOK、No.01、No.55、記録、カード化、依頼の基礎ロジックは既に存在するため、今後は未確定部分を設計で確定しながら、それらを一連の実プレイへ接続していく。
